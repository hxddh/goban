# v1.70 之后：下一版评估 —— 再显著地简一层

评估日期：2026-09-29。基准 main（v1.70.0）。要求：**继续显著地变得更简洁、优雅**。

方法同上一版：Chromium 1280×800 逐状态截图，数看得见、点得到的控件（棋谱每一手不计），再数弹层。

| 状态 | v1.70 可点控件 |
|---|---|
| 首次打开 | 21 |
| 对局中 | 19 |
| 终局 | 24 |
| 弹层种类 | 6（设置 · 快捷键 · 存档 · 统计 · 练习 · 确认） |

## 看到的

1. **空棋盘上还有两个用不上的按钮**：「悔棋」（灰着）和「提示」（第一手下哪儿不需要提示）。
2. **翻页五个按钮**：开局 · 上一手 · 回到最新 · 下一手 · 终局。开局 / 终局有 Home / End，
   也可以直接点棋谱第一手、最后一手；真正常用的只有上一手、下一手，和看旧手时「回到最新」。
3. **「存档」与「统计」是两个弹层**，统计弹层只有一张四列小表和一行连胜。两者都是「看过去的对局」。
4. **顶栏的「?」**只打开一张快捷键表，一年用不了几次，却和「新局」「设置」并排常驻。
   而且那张表里「棋谱」一行还写着「侧栏里复制 / 导出…」—— v1.70 挪走后它已经过时。
5. **终局卡四个动作**：重下第 N 手 · 练这一手 · 看复盘 · 再来一局。「再来一局」就是顶栏高亮的「新局」；
   「练这一手」在复盘面板里也有。
6. 两处装饰性文字：顶栏的「五子棋」（窗口标题栏已经写着），对阵行中间的「对」。

## 这一版：五件事，都是「减」

1. **空棋盘不显示悔棋、提示**（与 v1.68 空棋盘不显示翻页同一条规则）。
2. **翻页 5 → 3**：上一手 · 回到最新 · 下一手。开局 / 终局交给 Home / End 和点棋谱。
3. **「存档」「统计」合成一个「对局」弹层**：最上面一行战绩（胜负平 · 胜率 · 连胜），下面最近对局、
   命名存档、棋谱文件、备份。侧栏底部两个文字链变一个；弹层 6 → 5。
4. **快捷键从顶栏挪进设置**：设置弹层底部一行「快捷键」，按 `?` 照旧直接打开；顺手把那张表改对、删掉
   「点击落子」「Tab」这类不言自明的行。
5. **终局卡只留两个动作**：重下第 N 手（主）· 看复盘。再来一局用顶栏「新局」，练这一手在复盘面板里。
   另去掉顶栏「五子棋」与对阵行的「对」。

不动的：棋盘、配色、对局流程、引擎、练习弹层。

  「练这一手」在复盘面板；闸门逐个点一遍；
- 快捷键表里写的每一条，按下去都管用（沿用 v1.64 的那条闸门），且不再提到侧栏里已不存在的按钮；
- 旧有全部测试照旧通过。

### 需要你决定的

- **翻页 5 → 3**：用鼠标跳到开局的人要改点棋谱第一手。我的判断是值得。
- **终局卡 4 → 2**：「再来一局」离手最近，去掉后要看顶栏的「新局」。它本来就是顶栏里唯一高亮的按钮，
  我的判断是值得；如果你更看重终局时的顺手，可以保留「再来一局」、只去掉「练这一手」（终局 ≤ 19）。
