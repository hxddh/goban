# v1.70 之后：下一版评估 —— 再显著地简一层，并把 bug 挖干净

评估日期：2026-09-29。基准 main（v1.70.0）。要求：**继续显著地变得更简洁、优雅**。

方法同上一版：Chromium 1280×800 逐状态截图，数看得见、点得到的控件（棋谱每一手不计），再数弹层。

| 状态 | v1.70 可点控件 |
|---|---|
| 首次打开 | 21 |
| 对局中 | 19 |
| 终局 | 24 |

## 看到的

1. **空棋盘上还有两个用不上的按钮**：「悔棋」（灰着）和「提示」（第一手下哪儿不需要提示）。
2. **翻页五个按钮**：开局 · 上一手 · 回到最新 · 下一手 · 终局。开局 / 终局有 Home / End，
   也可以直接点棋谱第一手、最后一手；真正常用的只有上一手、下一手，和看旧手时「回到最新」。
3. **「存档」与「统计」是两个弹层**，统计弹层只有一张四列小表和一行连胜。两者都是「看过去的对局」。
4. **顶栏的「?」**只打开一张快捷键表，一年用不了几次，却和「新局」「设置」并排常驻。
   而且那张表里「棋谱」一行还写着「侧栏里复制 / 导出…」—— v1.70 挪走后它已经过时。
5. **终局卡四个动作**：重下第 N 手 · 练这一手 · 看复盘 · 再来一局。「再来一局」就是顶栏高亮的「新局」；
   「练这一手」在复盘面板里也有。
6. 两处装饰性文字：顶栏的「五子棋」（窗口标题栏已经写着），对阵行中间的「对」。

## 挖出来的 bug（v1.70 上逐个复现过）

走了一遍交互脚本：思考中打断（新局 / 悔棋 / 换难度 / 切语言）、看旧手时落子 / 提示 / 悔棋、终局卡每个动作、
粘贴坏 / 好 SGF 与续下、窄窗口、双人下连切规则、首次打开就点复盘 / 统计、终局后悔棋、命名存档。

| # | 现象 | 原因 |
|---|---|---|
| B1 | swap2 换成自由 / 禁手（或 swap2 局里改规则后点新局），**「平衡开局 · 请落第 1 子」提示条还留在棋盘上** | `reset()` 清了 swap2 状态却没收起提示条 |
| B2 | **一局已经下完，点「新局」/「再来一局」仍弹「放弃当前对局？」** | 确认只看「盘上有没有子」，不看这局是否已结束（结束的局早已自动存进对局库） |
| B3 | 终局卡与复盘面板的「**练这一手**」点下去是「这一手没有可练的战术题」，再落回普通练习 | 按钮按「可证明的失着」显示，题库按「能否出成一道题」判，两套判据不一致 |
| B4 | 首次打开就点「复盘」，只弹一句「先下几手再来复盘」 | 没有可复盘的对局时按钮仍可点 |
| B5 | 文案过时：快捷键表「棋谱」一行写着「侧栏里复制 / 导出…」；Esc 一行说复盘是弹层；练习做完提示「在『每日』里」；侧栏开关写成「☰」（图标早已不是 ☰） | v1.64 / v1.70 改了界面，文案没跟上 |

## 交互：提示只说屏幕上看不出来的事

一局里弹出的提示条，有一半是在复述刚刚看得见的变化：「新局已开始」「难度：困难」「人机对战」「主题：夜盘」
「Interface language: English」「已回到最新一手」「提示：黑 · 虚线十字」。棋盘清空、选中格变亮、虚线十字出现，
这些本身就是反馈，再弹一句是噪音。保留的是**看不出来的**：出错、被拦（禁手、须回到最新一手）、规则说明、
「从下一局起生效」、导入 / 备份的结果。

## 这一版：五件「减」 + 修上面五个 bug + 提示只说看不出来的事

1. **空棋盘不显示悔棋、提示**（与 v1.68 空棋盘不显示翻页同一条规则）。
2. **翻页 5 → 3**：上一手 · 回到最新 · 下一手。开局 / 终局交给 Home / End 和点棋谱。
3. **「存档」「统计」合成一个「对局」弹层**：最上面一行战绩（胜负平 · 胜率 · 连胜），下面最近对局、
   命名存档、棋谱文件、备份。侧栏底部两个文字链变一个；弹层 6 → 5。
4. **快捷键从顶栏挪进设置**：设置弹层底部一行「快捷键」，按 `?` 照旧直接打开；顺手把那张表改对、删掉
   「点击落子」「Tab」这类不言自明的行。
5. **终局卡只留两个动作**：重下第 N 手（主）· 看复盘。再来一局用顶栏「新局」，练这一手在复盘面板里。
   另去掉顶栏「五子棋」与对阵行的「对」。

6. **修 B1–B5**；B3 的修法是「练这一手」只在题库真能出这道题时出现（终局卡里它本就去掉了，复盘面板里照此判）；
   B4 的修法是没有可复盘的对局时不显示「复盘」。
7. **去掉复述性的提示条**（上一节那七种）。

不动的：棋盘、配色、对局流程、引擎、练习弹层。
