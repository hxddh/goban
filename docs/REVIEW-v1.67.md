# v1.67 之后：下一版评估 —— 简洁、优雅、快速

评估日期：2026-09-29。基准 main `5b9dbdd`（v1.67.0）。目标来自用户：**产品目标要简洁，体验要优雅，快速**。

> **状态（v1.68.0 已实施）**：F1 时间管理（困难 / 极限平均用时 −37% / −38%，对 v1.67 不显著变弱）、F3 撤下 C2、S1 / S2 / E1 已做。
> F2 没做：实测全盘扫描只要 42 ms，那 1.3 秒是扫描之后的搜索，已由 F1 处理。

方法：Chromium（Playwright，1280×800，2×）量启动、重绘、控件数与每档电脑实际等待；引擎用逐层记录的
C3 副本自对弈（困难，每手 2 秒，6 局），记录每一层的最佳手与时刻，离线模拟时间管理策略。WKWebView /
WebView2 的绝对数字会不同，这里看的是比例与大头在哪。

---

## 一、结论

1. **慢的只有一处：电脑想得太久。** 启动（首次绘制约 0.1 秒、就绪约 0.29 秒）、整盘重绘（1.2 毫秒）、
   后台引擎就绪（加载后 20 毫秒内）都已经很快。困难每手 2.0 秒、极限 5.0 秒，**每一手都用满预算**，
   哪怕答案早就定了：
   - 需要完整搜索的手，最终那一手**中位数在预算的 28% 就已确定**，之后再没变过；48% 的手在前四分之一
     时间内就定了；
   - 每手平均 **26% 的时间花在最后一层没搜完的迭代上**，结果基本丢弃；
   - 「对手有连续冲四杀、必须防」的局面平均要 **1.3 秒**——现在的做法是把全盘每个空点都试一遍。
2. **一打开就有 34 个可点的控件**，其中 8 个此刻没有意义（5 个翻页、复制、导出、复盘），另有规则三选一
   这种一次性偏好与难度同级常驻。
   顶栏「0/0 00:00」、侧栏「已存 05:02」在空棋盘上也是噪音。
3. **首次提示条压在棋盘底边上**，挡住最后一行格线。
4. **C2 引擎（`ai2.js`）已经不担任任何难度档**（v1.66 起四档都是 C3），却仍在主页面与后台线程里各加载一份。

## 二、快：实测

### 2.1 启动与重绘（Chromium，三次取值）

| 项 | 数值 |
|---|---|
| 首次绘制 | 92–108 ms |
| DOMContentLoaded / load | 283–294 ms |
| 脚本执行合计 | 195 ms（`ai3.js` 建棋型表约 22 ms 最重） |
| 后台引擎就绪（load 之后） | 2–22 ms |
| 整盘重绘（1488 px 画布） | 1.2 ms |
| JS 堆 | 2.5–3 MB |

结论：不是瓶颈，这一版不动。

### 2.2 电脑落子（经真实后台线程，一个开局后的中盘局面）

| 档 | 预算 | 实际 |
|---|---|---|
| 入门 | 240 ms | 125 ms |
| 普通 | 400 ms | 408 ms |
| 困难 | 2000 ms | 2001 ms |
| 极限 | 5000 ms | 5003 ms |

### 2.3 困难档一局里时间花在哪（自对弈 131 手）

| 阶段 | 手数 | 平均 |
|---|---|---|
| 成五 / 挡五 / 自己的连续冲四 | 57 | 0 ms |
| **防对手的连续冲四（deny）** | 26 | **1285 ms** |
| 完整搜索 | 48 | 约 1600 ms（有的局面中途算出胜负提前结束） |

### 2.4 时间管理的模拟（完整搜索的 76 手，离线重放逐层记录）

| 策略 | 平均 | 与原选择不同 |
|---|---|---|
| 现在（用满预算） | 1599 ms | — |
| 过了 45% 预算就不再开新一层 | 1158 ms | 1% |
| 再加：最佳手连续 3 层不变且已过 15% 预算就落子 | 1010 ms | 3% |

新一层通常要花前面所有层之和的 2–3 倍：过了一半预算才开的那一层几乎不可能搜完，这段时间是纯浪费。

## 三、简与雅：实测

**一打开（全新用户，人机）可点的 34 个控件**：顶栏 6（悔棋 · 提示 · 新局 · 快捷键 · 设置 · 侧栏）、
首次提示 2、对局设置 12（模式 2 · 难度 4 · 执子 3 · 规则 3）、翻页 5、棋谱文件 4（复制 · 导出 · 导入 · 粘贴）、
学习 3（复盘 · 练习 · 每日）、存档 · 统计 2。设置弹层 10 个控件，弹层共 6 种。

此刻没有意义、却占着位置的：翻页 5、复制、导出（空棋盘没有东西可翻、可复制）、复盘（没有对局）。
规则三选一（自由 / swap2 / 禁手）是一次性的偏好，绝大多数人从不改，却和「难度」同级常驻。

---

## 四、方案（v1.68）

### 快

- **F1 时间管理**：过了 45% 预算不再开新一层；最佳手连续 3 层不变且已过 15% 预算就落子。困难与极限都用。
  **验收**：新难对旧难（同一标称预算）配对计分**不显著更弱**；困难档完整搜索的平均等待从约 1.6 秒降到约
  1.0 秒（按 2.4 的模拟）；极限同比例。
- **F2 防连续冲四只试相关的点**：对手的连续冲四杀只能在它的冲四线上被挡，或者被我方反冲四打断。候选只取
  「对手成四 / 成五的点」与「我方能走出冲四的点」，逐一验证。**验收**：在自对弈抽出的全部 deny 局面上，
  得到的安全点集合与全盘扫描**逐个相同**；平均耗时从 1.3 秒降到 0.1 秒量级。
- **F3 撤下 C2**：主页面与后台线程不再加载 `ai2.js`；它留在仓库里只给强度测试当参照对手。

### 简

- **S1 按对局状态显示**：还没落子时不显示翻页条、复制、导出、复盘，也不显示顶栏的手数与用时和侧栏的「已存」；
  落下第一子后出现。
- **S2 规则挪进设置**：侧栏的对局设置只留模式、难度、执子三行；规则进设置弹层（选了非「自由」时，
  侧栏信息行写一个「禁手」/「swap2」标记，不会忘了自己在什么规则下）。
- **验收（闸门）**：全新用户一打开可点的控件 **≤ 22**（现在 34）；落子后翻页、复制、导出、复盘都在。

### 雅

- **E1 首次提示条不压棋盘**：移到棋盘下方的留白里，不盖住格线。
- **E2 用不了的就不显示**：空棋盘时的一排灰按钮（见 S1）是这一条的主要来源。

---

## 五、需要你决定的

- **S2 规则挪进设置**：这会让喜欢连珠 / swap2 的玩家多点一下。我的判断是值得——它是一次性偏好，不是每局都换的。
- **F1 的代价**：约 3% 的手会与「用满时间」时的选择不同。验收要求对局尺上不显著更弱；如果显著更弱，就只保留
  「过半不开新一层」那一条（1% 不同，平均 1.16 秒）。
