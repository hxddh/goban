# v1.74 之后：下一版评估 —— 真正只剩一块棋盘，小窗口也一样好看

评估日期：2026-09-30。基准 main（v1.74.0）。要求：继续简洁、优雅，挖 bug。

方法：Chromium 在 760×600 / 1024×600 / 1024×768 / 1280×720 / 1280×800 / 1440×900 六档窗口下，
逐状态截图并量棋盘边长；再跑一轮交互探测：新局卡片的键盘操作、菜单开着时按快捷键、卡片开着点棋盘、
时间线的键盘操作、swap2、复盘开着按 N、练习弹层。

## v1.74 的问题：窗口一小，棋盘就被挤没了

v1.74 把终局卡和复盘卡片放进「坞」里。横向宽窗口放在棋盘右侧（棋盘不动），**其余窗口一律放在棋盘下方**，
棋盘要让出坞的高度。实测棋盘边长（px）：

| 窗口 | 首次打开 | 对局中 | 终局 | 复盘 |
|---|---|---|---|---|
| 1440×900 | 808 | 808 | 808 | 780 |
| 1280×800 | 708 | 708 | 708 | 680 |
| 1280×720 | 628 | 628 | 628 | 600 |
| 1024×768 | 582 | 676 | 512 | **407** |
| **1024×600** | 414 | 508 | 344 | **239** |
| **760×600** | 414 | 508 | 344 | **239** |

1024×600 是这个应用支持的最小窗口。在这个窗口里复盘，棋盘只有 **239px**，棋子小得看不清，而复盘恰恰是要看棋子的时候。
第一次打开时，初见那一句话也放在棋盘下方，把棋盘从 508 挤到 414。

判断「放在右侧」的条件太严了（宽 − 高 ≥ 480）。1024×600 里棋盘被高度限在 508，左右各空着 258px，
本来放得下一张 260 宽的卡片。

## 还剩两块棋盘

v1.74 把侧栏去掉了，但**练习还是一个弹层，里面有自己的一块小棋盘**（1280×800 下题盘 544，主棋盘 708）。
打开练习，主棋盘在背后虚掉，前面浮着另一块更小的棋盘。这是 v1.74 评估时说定要留到这一版的事。

## 这一版（v1.75）

1. **练习搬到主棋盘上，练习弹层退役。** 点「⋯ → 练习」（或初见那句「先做今天的 5 道题」），主棋盘直接换成题目局面；
   顶栏写「每日挑战 · 1 / 5」；题型（今日 · 全部 · 成五 · 防守 · VCF · 禁手）、题目、反馈、提示 · 看答案 · 下一题
   都在坞里那张卡片上；「回到对局」回到刚才那一局，一手不差（它本来就自动存着）。
   练习期间，悔棋 · 提示 · 新局 · 时间线收起。题目逻辑（出题、判题、分层提示、复习间隔）一行不动，只换它画在哪块棋盘上。
2. **坞在所有横向窗口里都放在棋盘旁边**（宽 ≥ 高就算横向）。棋盘两侧放得下，就原地不动；放不下，就把棋盘和坞
   当成一组居中，棋盘必要时略缩，但**永远不再为坞让出高度**。只有竖长的窗口才把坞放在棋盘下方。
   初见那一句话也随坞放到旁边。
3. **修 B13**：卡片里的回车只在焦点落在「开始」上（或不在任何选项上）时才开局，落在选项上时回车就是选它。
4. **修 B14**：菜单或卡片开着时，快捷键只做一件事：先把浮层收起来。

不动的：引擎、规则、存储、题库与判题、复盘内容、设置 / 记录两个弹层。

### 验收（闸门）

| 项 | v1.74 | 目标 |
|---|---|---|
| 1024×600 复盘时棋盘边长 | 239 | **≥ 460** |
| 1024×600 终局 / 首次打开 | 344 / 414 | **≥ 460** |
| 760×600 各状态 | 最小 239 | **≥ 420** |
| 练习时应用里有几块棋盘 | 2 | **1**：题目画在 `#board` 上，与对局棋盘同一个位置、同样大 |
| 练习时看得见的控件 | — | **≤ 11** |

- 练习 → 回到对局：手数、当前查看的那一手、终局卡状态与进入前完全一样；练习期间悔棋 · 提示 · 新局 · 时间线都不出现；
- 练习弹层里原有的每一样都还能到：六个题型、提示、看答案、下一题、错题本、「回到原局」（题目来自哪一局）、每日进度；
- B13、B14、B15 各一条闸门，在 v1.74 上失败；
- 旧的练习测试（test-daily、test-cross 的 AB / AR / Y 等）照测功能，只改它们找按钮、找棋盘的位置。

### 工作量与风险

练习的界面层要重写：弹层的 HTML 挪进坞，`practice.js` 里画题盘的地方改画到主棋盘上。它有自己一套画题逻辑
（答案点、VCF 序号、禁手点），好在从 v1.39 起就和主棋盘用同一个画子函数（`paintStone`），闸门 Y 守着这一点。
坞的新布局是纯 CSS 加一个量宽度的函数。比 v1.74 小，一个版本做得完。

### 需要你决定的

- **练习时要不要留着「新局」？** 我的判断是不留：练习时顶栏只剩「⋯」，卡片上有「回到对局」，想开新局回去再点。
  留着的话，就得回答「在做题时点新局，是开新局还是换一道题」这种歧义。
