# v3.1 之后：v3.2 —— 看得准

评估日期：2026-10-18。基准：main（v3.1.0）。仍然**只看对弈本身**。

> **状态：已在 v3.2.0 实施。** 你的决定：
> 1. 评估权重改用自对弈拟合值；
> 2. 极限每手 5 → 2.5 秒。
>
> 实测见 `.github/release-notes/v3.2.0.md`。

## 起点：v3.1 留下的缺口

v3.1 让引擎快了一倍，但**自由规则下的极限没有变强**：对 v3.0 的极限 23 : 19，持平。这一版先回答一个问题：极限到底卡在哪。

## 方法

1. 换一种开局量强弱。
   - 此前用随机 4 子开局，自由规则下黑方赢七到九成，一组开局两边各执一次黑，多半是各赢一局，量不出谁强。
   - 这一版改用 **5 子开局**：黑 3 子、白 2 子、轮白走，等于把黑的先手还给白。黑方胜率降到六成多，同样多的对局能看出更小的差别。
2. 每一个提议都做成原型，与现在的引擎在同样的时限下对下，看胜负。

## 极限：五种办法，四种没用、一种更差

| 试法 | 做了什么 | 对现在的极限 |
|---|---|---|
| 搜得更宽 | 根 26 → 32，内层 14 / 10 / 8 → 18 / 13 / 10 | 39 : 32，持平 |
| 后排的手先浅搜 | 排在第 4 位以后的手先少搜一层，可能更好时再按原深度重搜。5 秒里从 11 层搜到 13 层 | 10 : 14 |
| 活三连杀 | 每手先花三成时间找自己的活三连杀，再花三成拆对手的 | **16 : 30，更弱** |
| 评估权重拟合（见下） | | 34 : 35，持平 |
| **只给 2.5 秒** | 时间减半 | **22 : 24，量不出差别** |

最后一行最要紧：**5 秒里的后一半时间没有换来可测的棋力**。极限之所以强于困难，靠的是「时间用满」：困难一旦最佳手稳定就提前落子（平均 0.44 秒），极限则每一手都算到底。多出来的那 2.5 秒，并没有带来什么。

结论：在这套引擎里，极限的搜索已经到顶。再多的时间、更深的搜索、更宽的搜索都换不来棋力。要让极限再强，需要不同的东西（比如棋型之外的评估），这不是一版能做完的事。

## 评估权重：普通、困难明显更强

引擎给每个空点按「各方向的棋型」和「组合型」打分。这两张表一共约 20 个数，是手定的，从 v1.65 起没有动过。

### 怎么拟合

1. 困难档自对弈 1100 局。开局随机 3–6 子，每手 80ms。
2. 取 18195 个**平静局面**：没有五、没有活四或双四、轮到的一方没有四三。战术局面由搜索负责，不进样本。
3. 用每个局面的分数去预测这一局最后谁赢（Texel 式逻辑回归），按预测误差逐个调整权重，做两轮（第二轮用第一轮权重的自对弈加样本）。
4. 冲四与五的分值不参与拟合，保持原值。

预测误差 0.197 → 0.173。变化最大的几项：

| 棋型 | 原值 | 拟合后 |
|---|---|---|
| 眠三（单方向） | 48 | 108 |
| 冲四（单方向，作为「还差一步成五」） | 170 | 534 |
| 四三 | 1400 | 2004 |
| 冲四 + 二 / 三 | 150 | 628 |
| 双三 | 900 | 420 |

拟合的结果是：冲四比原来以为的更值钱，双三没有原来以为的那么值钱。

### 对下

5 子开局，每个开局两边各执一次黑。p 值为双侧。

| 档 | 新权重对原权重 | |
|---|---|---|
| 普通 | **68 : 26**（和 2；p < 0.001） | 明显更强 |
| 困难 | **33 : 15**（p = 0.01） | 明显更强 |
| 困难（禁手规则） | 31 : 17（p = 0.06） | 同一方向 |
| 极限 | 34 : 35 | 持平 |
| 入门（只会挡冲四的新手对它） | 55 / 100（原 54 / 100） | 不变：入门的强弱由「漏挡活三」的概率决定 |

## 顺带查的：同一局面会不会总下同一手

- 同一局面问两次，困难 52 / 52、普通 103 / 105 给出同一手。
- 但照搬一盘赢过的棋重下，困难只有 2 / 6、普通 1 / 6 能再赢一遍：开局的对称变化和计时的细微差别会让棋局走散。
- 这一版不动。
