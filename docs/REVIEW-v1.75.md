# v1.75 之后：下一版评估 —— 每一层都进得去、出得来，出来时什么都没丢

评估日期：2026-09-30。基准 main（v1.75.0）。要求：继续简洁、优雅，挖 bug。

> **状态（v1.76.0 已实施）**：复盘 Esc / 关闭离开并回到结局；终局 ↔ 复盘棋盘不动；规则进新局卡片；B16–B21 修好。待定项按建议：离开复盘回到最后一手、终局卡回来。

方法：Chromium 1280×800 / 1024×600 / 900×1000（竖）逐状态截图、量棋盘与坞的位置；再跑一轮交互探测：
练习中换主题 / 语言 / 规则、练习中电脑落子、练习时的时钟、看答案、做完每日五题、终局 → 复盘 → 关闭、
复盘里按 Esc、对局中翻看前面的手、电脑思考时悔棋。

## v1.75 做到了什么，还差什么

v1.74、v1.75 两版把界面收成了「一块棋盘 + 顶栏 + 棋盘旁一张卡片」。控件数已经很少
（首开 3、对局 5、终局 7、复盘 9、练习 10），这一版不再数控件。

剩下的问题出在**状态之间的切换**。应用现在有五种状态：空盘、对局、终局、复盘、练习。
练习是 v1.75 新做的，进出都干净（「回到对局」或 Esc，回来一手不差）。其余几种的进出各有各的规矩：

| | 怎么进 | 怎么出 | 出来以后 |
|---|---|---|---|
| 练习 | ⋯ → 练习 | 「回到对局」或 **Esc** | 原局、原来那一手，一手不差 ✓ |
| 复盘 | 终局卡「看复盘」、⋯ → 复盘 | 卡片上「关闭」；**Esc 没反应** | **停在失着那一手；终局卡没了，结果也没了**；顶栏还写着「复盘 13/14」 |
| 翻看前面的手 | ← / 时间线 | → / End | 顶栏写「复盘 3/4」，**可这时并没有在复盘** |

另外两处「不稳」：

- **终局 → 复盘，棋盘会跳。** 1280×800 下棋盘从 708 缩到 680，往右挪 14px；坞从 256 宽变成 270 宽。
  终局卡和复盘卡是同一个位置的两张卡片，棋盘本来不该动。
- **复盘时「悔棋」是灰的但还在。** 复盘是看，不是下，灰按钮占着顶栏最显眼的位置。

## 设置里还混着一项「这一局」的事

v1.74 把模式 · 难度 · 执子 · 思考时长都放进了「新局」卡片：**这一局怎么下，在开局时定。**
唯独**规则**（自由 · swap2 · 禁手）还留在设置里。结果是对局中改规则，只能弹一句
「从下一局起用禁手规则」，而新局卡片上又看不到规则，开新局时并不知道这一局用的是哪个规则。

把规则挪进新局卡片以后，设置里剩下的就全是「外观和声音」：主题 · 坐标 · 语言 · 音效。
两个面各管一件事，不再有「改了但不生效」的那句提示。

## 挖出来的 bug（v1.75 上复现过）

| # | 现象 | 原因 |
|---|---|---|
| B16 | 练习时在设置里换主题（木纹 → 夜间），**题目那块棋盘还是木纹**，页面其余部分已换成夜间 | 换主题只重画了对局棋盘；练习棋盘要等下一题才重画 |
| B17 | 练习时把语言换成 English，**顶栏仍是「每日挑战 · 第 1 / 5 题 · 答对 0」，题目仍是「黑先 · 找出连续冲四取胜的第一手」、来源仍是「内置题」**；只有按钮换成了英文 | 换语言时重写了静态文字和对局状态，练习卡片上从状态拼出来的文字没重建 |
| B18 | 一手没下就点「看答案」，红字写着「答案：G10。**✗ 这一手无法把对方逼死**……」 | 看答案沿用了「下错了」的那句话，可用户根本没下 |
| B19 | 练习时，藏在顶栏里的**对局时钟还在走**（做 9 秒题回来，对局时间多了 9 秒） | 练习只把时钟藏起来，没停 |
| B20 | 终局 → 看复盘 → 关闭：**终局卡消失，棋盘停在第 13 手，顶栏写着「复盘 13/14」**；按 End 回到最后一手，终局卡也不再回来 | 打开复盘时终局卡被收起，关闭复盘时没有放回来 |
| B21 | 复盘时按 Esc 没反应（练习时按 Esc 会回到对局） | Esc 的处理里没有复盘这一层 |

另外一处措辞：对局中按 ← 翻看前面的手，顶栏写「复盘 3/4」。「复盘」在这个应用里是另一个状态
（有曲线、有解释），翻看前面的手不是它。时间线右端本来就写着「3 / 4」，顶栏不必再说一遍。

其余探测都正常：练习时电脑照常落子，回来时那一手已在棋盘上；电脑思考时悔棋，思考作废、
不会落下一手；做完每日五题有总结和「再来一轮」；鼠标打开练习时「回到对局」不显示焦点框
（用键盘打开时才显示，这是对的）；900×1000 竖窗口里练习卡片在棋盘下方，不压棋盘。

## 这一版（v1.76）

1. **复盘和练习一样，是一层「进得去、出得来」的东西。**
   - 卡片上「关闭」或 **Esc** 都能离开复盘；
   - 离开复盘，**回到最后一手，终局卡回来**（结果、值得记住的一手、「重下第 N 手」都在）；
   - 复盘时顶栏不显示「悔棋」。
2. **终局 ↔ 复盘，棋盘不动。** 两张卡片同宽，复盘曲线在时间线那一行里长高，不再挤棋盘。
   闸门：1280×800、1024×600 两档下，终局与复盘的棋盘位置和边长完全一样。
3. **规则挪进「新局」卡片**（模式 · 难度 · 执子 · 规则，困难 / 极限另有思考时长），上一局的选择默认选好。
   设置只剩主题 · 坐标 · 语言 · 音效。对局中不再有「从下一局起生效」那句提示。
4. **翻看前面的手时，顶栏不再写「复盘」**，仍显示这一局的状态（「轮到你」「白棋胜」）；位置看时间线右端。
5. **修 B16–B21。** 练习里的题目、提示、来源、顶栏在换主题、换语言时当场重画；看答案写「答案：G10」加
   正解说明，不再说「这一手」；练习时对局时钟停走，回来接着走。

不动的：引擎、规则本身、存储、题库与判题、复盘内容、布局（v1.75 的坞与棋盘尺寸）。

### 验收（闸门）

| 项 | v1.75 | 目标 |
|---|---|---|
| 复盘里按 Esc | 没反应 | 离开复盘 |
| 离开复盘后 | 停在失着那一手，终局卡没了，顶栏「复盘 13/14」 | 最后一手、终局卡在、顶栏「白棋胜」 |
| 终局 → 复盘，棋盘位置 / 边长（1280×800） | (286, 50, 708) → (300, 50, 680) | 不变 |
| 复盘时顶栏看得见的「悔棋」 | 有（灰） | 无 |
| 规则在哪 | 设置（对局中改只对下一局生效） | 新局卡片；设置里没有规则 |
| 翻看前面的手时顶栏 | 「复盘 3/4」 | 这一局的状态，不含「复盘」 |
| 练习中换主题 / 语言 | 题盘不换色；顶栏、题目、来源仍是中文 | 当场换 |
| 一手没下点「看答案」 | 「✗ 这一手无法把对方逼死」 | 不出现「✗」「这一手」 |
| 练习 10 秒，回来后对局时钟 | 多 10 秒 | 不变（误差 ≤ 1 秒） |

- 每一条 B16–B21 在 v1.75 上失败；
- 规则搬家不改变规则本身：自由 / swap2 / 禁手三种对局、swap2 的交换流程、禁手判定的现有测试照旧通过；
  旧存档里 `prefs.rule` 照读，作为新局卡片的默认选择；
- 测设置弹层里规则那一行的旧测试改为测新局卡片里的规则行，在发布说明里写明。

### 工作量与风险

比 v1.75 小。复盘的进出和终局卡的恢复在 `app.js` 里集中在 `openReview` / 关闭复盘 / `hideEndCard` 三处；
规则进卡片是把设置里的一行挪过去，并入卡片已有的「选好点开始才生效」逻辑（v1.74 起就这样处理模式和难度）。
练习的三个 bug 都在 `practice.js` 的重画与文案上。风险最大的是规则搬家碰到 swap2 开局，闸门照例覆盖。

### 需要你决定的

- **离开复盘时回到哪一手？** 我的判断是**回到最后一手、终局卡回来**：复盘是看这一局的一种方式，看完就回到这一局的结局。
  另一个选择是停在你刚才看的那一手（适合看完想从那里「重下」的人，但「重下这一手」在复盘卡片上本来就有）。

`@native-sdk/core` 最新仍是 0.10.1，这一版无需升级。
