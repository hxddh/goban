## v1.28.0 · 本版内容

### app.js 拆分(已完成)

2460 → 2030 行,拆出 `engine.js`(Worker 生命周期与降级)、`ui.js`(展示层)、
`sgfio.js`(SGF 导出),行为零变化。导入 / 存档快照 / swap2 状态机**有意不拆**:
它们一次性改写十几个模块变量,搬走只是转移耦合。

### 引擎 A/B 擂台(已完成)

`scripts/arena.mjs`:工作区引擎 vs 任意 git ref,成对中局局面 + 确定性节点预算。
两个设计要点写进了脚本注释——空盘开局无分辨力(黑必胜)、开局须按对称去重。

### 引擎强度(已尝试,未采纳)

历史启发、PVS、两者组合、VCT 加深四类改法逐一实测,得分散布在对称基准附近
(最好 +2,同候选换预算即 −2),按仓库对引擎的纪律不接受无可测收益的改动,
引擎源码保持与 v1.27.0 一致。**这条记录的价值是:下次别再盲试这四类。**

真要再碰引擎,已知的前提是:
- 先把擂台 `positions` 加大(28 局只能识别大效应);
- 优先怀疑 C1 战术级联(它在多数局面先于 C2 搜索决出胜负),而不是通用 α-β 优化。
