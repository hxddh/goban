## v1.26.0 · 本版内容

三项都来自对 v1.25.3 的实测排查，均不碰 core 规则层、不碰两个引擎、不碰对局主流程。

### P0 · 顶栏按钮被侧栏埋掉（已修）

侧栏 `z-index:30` 盖住顶栏 `z-index:20`，悔棋/提示/新局/?/☰ 正压在其下：
透出虚影但吞掉所有点击，而侧栏刻意不放这些主按钮的副本，
侧栏一开就没有鼠标途径悔棋或开新局。520–1728px 全宽度复现，自 v1.24.0 起存在。

改法：侧栏从顶栏下方开始（`top: var(--chrome-h)`），任何宽度下都不重叠;
顶栏提到遮罩之上，窄窗浮层模式下也可点。
「把顶栏缩到棋盘一侧」的方案实测在 ≤820px 会把按钮挤出边界，已排除。

### P1 · 每日挑战题库 8 → 53 题 + VCF 题型（已完成）

8 道内置题时，每日 5 题与前一天平均重复 3.21 题，30 天内同题约做 19 次。
现内置 53 题（23/18/12），引擎自对弈生成 + 逐题走 practice.js 判定验证
（`scripts/gen-puzzles.mjs`，确定性可复现）。新增 VCF 题型，判定复用引擎已导出的
`findVCF`，不复制搜索逻辑。实测日间重复 **0.45 / 5**。

### P1 · CI 门禁（已完成）

此前三个 workflow 全为 dispatch-only，PR 与 push 都不跑测试，代码发版才第一次被测。
新增 `ci.yml`：PR/push 跑单测 + 交叉回归 + 每日回归，push 到 main 另跑强度基线；
`REQUIRE_PLAYWRIGHT=1` 让 CI 里缺浏览器判失败，避免浏览器套件空过。
