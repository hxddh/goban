# Goban 路线图 — v1.25.0

> 评估基准:v1.24.0(战术练习 + 对局统计 + 代码模块化)。
> 已具备:C1/C2 双引擎、复盘 3.0(评分曲线/失着/推演/评注 SGF)、swap2 平衡开局、
> 战术练习、对局统计、四套棋盘主题、SGF 全链路、多存档槽、macOS/Windows 双平台发布。

## 现状判断

v1.19–1.24 六个版本把「单机对弈 → 复盘 → 练习 → 统计」这条学习闭环做深了。
当前最大的两块空白不在功能广度,而在**对局本身的完整性**:

1. **规则完整性**——只有自由规则(freestyle)。swap2 解决了先手优势的开局侧,
   但竞技五子棋的另一半——**禁手(Renju)**——还没有。
2. **对局张力**——顶栏时钟只是走时显示,没有任何时限约束,
   人机对局缺少「读秒压迫感」,双人对局无法公平计时。

这两项都不引入新平台依赖(纯 core.js/app.js + AI 适配),符合现有架构节奏。

## v1.25.0 计划(按优先级)

### P0 · 品牌刷新:新 logo(本分支已完成)
- 新图标:木纹棋盘 + 黑子斜线连珠(胜形)+ 两枚白子,呼应应用内「原木」主题配色。
- 矢量源 `assets/icon.svg` 入库,`assets/icon.png`(1024×1024)由其渲染,后续改版只改 SVG。

### P1 · 计时对局
- 时制三档:**不限时 / 每步限时(如 30s)/ 包干制(如每方 10 分钟)**,侧栏·对局中选择。
- 超时判负,结果进入统计;顶栏时钟按时制切换显示(倒计时 + 低时预警变色)。
- AI 思考时间与时制联动:包干制下引擎预算随余时收缩(C1/C2 已有 deadline 机制,接入即可)。
- 存档/SGF:时钟状态随存档保存;SGF 导出写入 `TM` 属性。

### P1 · 禁手规则(可选,Renju 风格)
- 侧栏·对局新增规则开关:**自由 / 禁手**(黑方三三、四四、长连判负或禁落)。
- 棋盘上实时标注禁点(hover 提示 + 标记),误点禁点给出解释。
- AI 适配:黑方回避禁手、白方会利用禁点做杀;两引擎(ai.js / ai2.js)的胜形判定分支化。
- 复盘/练习兼容:禁手局的分析与题目生成遵循同一规则。
- 注:这是本版本工作量最大的一项,若 AI 适配超预期,可先发布「双人对战禁手」,人机禁手随 1.25.x 跟进。

### P2 · 每日挑战(视余量)
- 基于 practice.js:每天固定种子生成一组 5 题(内置题库 + 自身对局题混合),
  完成度与连续打卡天数进统计面板。零新增依赖,复用现有题型。

## 暂不做(backlog,含理由)

| 项 | 理由 |
|----|------|
| 联机对战 | 需要服务端/信令,超出「纯前端 + zig 壳」架构一个量级,单独立项评估 |
| 英文界面 i18n | 值得做,但应在 UI 稳定(禁手/计时落地)后一次性抽取文案 |
| 开局库浏览器 | 受众窄,先看 swap2 + 禁手上线后的使用反馈 |
| Linux 打包 | 等 Native SDK 的 Linux 支持成熟度,再评估 |
| 自动更新检查 | 低成本但涉及网络权限与隐私说明,合并到下次打包侧改动一起做 |

## 验收口径(沿用 v1.23.1 的质量硬化标准)

- 单测全绿 + 交叉回归(计时 × 悔棋/复盘/存档/导入、禁手 × swap2/练习/复盘)。
- 引擎强度回归:`scripts/test-strength.mjs` 对基线不劣化;禁手模式另立基线。
- 全量浏览器冒烟:0 控制台报错。
