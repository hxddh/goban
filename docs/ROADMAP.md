## v1.39.1 · 本版内容

修 v1.39.0 引入的一处:**绘制换到共享 `pitchFor` 时,命中判定没跟着改**。
`onBoardClick` 还用 `pad = cssW * 0.04` 的小数公式,且量的是含 1px 边框的边框盒。
改之前两边是同一个错公式互相抵消,是 v1.39.0 把它们拆开的。
实测:225/225 个交叉点中心仍判对,但**判定边界相对渲染最大偏移 1.48 CSS px**(格宽约 22px)。

闸门为什么没拦住:交叉闸门 Y 只盯渲染。第一版想在 Y 里补判定断言,写出来是**同义反复**
——用正确公式重算判定,`onBoardClick` 怎么写都通过(闸门 R 第一版、这次的探针,
同一个坑第三次)。改成源码层断言:`practice.js` 不许自己算格距,绘制与判定都必须引用
`pitchFor`;反证拿发出去的那份 v1.39.0 处理器跑,三条全红。闸门先剥注释再扫。

## v1.39.0 · 上一版内容

- **这个应用一直有两块棋盘**。`practice.js` 自带 `drawBoard()`:pad 13.44 / step 22.08
  (30 条线全在半像素上,正是 v1.35 在主棋盘修掉的缺陷)、半径 0.42(第四个各写各的值)、
  纯色圆片、无星位、**没有盘面**、dpr 不封顶。v1.35–v1.37 的每次改进都停在弹层边缘,
  而 练习(130 题)+ 每日 是一整个模式。改法是 `draw.js` 提出**无状态**的
  `paintPosition(ctx, opts)` 与共享的 `pitchFor(w)`,两块棋盘同一个画家。
  逐像素验证重构无副作用:四主题 × 两档 dpr 八种组合画布哈希与重构前**全等**。
- **统计弹层分量装反**:六个弹层里只有它把「关闭」提成主按钮,而旁边不可逆的「清空」
  用普通按钮,零对局时还可点。改为与存档弹层同一套写法(`.text-link.danger` + 空态禁用)。
- **第一次在真机上验证**。新增 `smoke-macos`(手动触发,不进 CI)。结论:**GitHub 的
  macOS runner 给得出可用会话** —— 应用真的启动、WKWebView 加载 `zero://app`、出了帧,
  全程 3 秒,`dispatch_errors=0`。并补上应用自己的桥处理器往返(写文件→读回→比对),
  这条路 Playwright 结构上到不了。仍做不到的是 WebView 像素。

## v1.38.0 · 上一版内容

起因是一句纠正:**这个应用不跑 Chromium**(macOS 是 WKWebView、Windows 是 WebView2),
而整套浏览器回归只跑 Chromium。查下去找到的不是我这几版的 bug,是我的方法**结构上看不见**
的一整类缺陷 —— 它们从 v1.9 躺到 v1.37,而我一路在报「审计干净」。

- **37 处 `color-mix()` 没有一处兜底**。不认这个函数的引擎会丢掉整条声明。按此模拟 v1.37 的
  样式表:侧栏 / toast / swap2 条 / badge / 主题选中态**五处背景算成 `rgba(0,0,0,0)`**,
  开关的「开」退回「关」的颜色,棋谱行退回按钮的 UA 黑字压在近黑面板上。改法是每条前面加一条
  纯色声明(自定义属性救不了,用 `@supports`)。支持的引擎上 139 个元素全量比对**差异 0 处**。
- **`backdrop-filter` 四处里三处漏 `-webkit-`**,其中一处是 `.modal-bg` —— 每个弹层背后的
  虚化。而 `.side` 从 v1.9 起就带着前缀,说明写的人知道要加。`user-select` 与 9 处
  `appearance` 同样补齐。
- **量文字用的字体两个平台都没有**:CDP 报的是 WenQuanYi Zen Hei。历次说明里的文字绝对像素
  值因此只是那个字体下的读数。见上方「这套回归能证明什么」与勘误表。

### 新增闸门(均做过反证,单测两道拿改动前的真实样式表跑出全部 36+13 处)

单测:color-mix 兜底闸、WebKit 前缀闸。
交叉:**V**(剔掉 color-mix 后界面不塌)、**W**(125% 字号下布局不塌)、**X**(钉住量测字体)。

## v1.33.1 · 上一版内容

复查确认未坏:五个脚栏入口、`清除存档`、侧栏四种关闭方式、减少动效下的弹层与棋盘、棋谱四个

## v1.33.0 · 上一版内容

四项都是界面上量得出来的缺陷,没有新功能。

- **打开应用只看得见 5 个按钮**。侧栏默认关闭,练习/每日/统计/存档/复盘 五个入口全在 ☰ 之后,
  且无任何首启引导。v1.32 优化的是"侧栏打开之后不用滚",落在了用户还没走到的地方。
  改法:首次运行展开一次(仅窗口宽 ≥900px,更窄时侧栏是盖住棋盘的浮层),之后记住用户的选择;
  并把脚栏**钉住**——v1.32 刮到 856px 只解决了 900 高这一个窗口,**1280×720 下五个入口又掉到
  线下**。sticky 之后 600/720/768/900 各高度实测 5/5 可见。入口按一条规则重排:
  打开面板的进脚栏,直接作用于本局的(复制/导出/导入/粘贴)留在「棋谱」区。
- **极限档每手 5 秒(深 8 秒)没有出口**。期间悔棋与提示禁用,状态只有静态的「电脑思考中…」。
  慢是引擎的正常代价,问题是不可中断。改法:悔棋在思考期间保持可点,点了即中断并撤回自己那一手
  (`gameGen` 加一 + 重启 worker);超过 1 秒状态栏开始计秒。中断后引擎照常工作(实测再落一子
  正常应手,5012ms)。
- **`prefers-reduced-motion` 只有一条规则**(`.think-dot`),开启后仍有 57 个元素在动。
  补成真正的媒体查询块,实测 57 → 0,正常态 58 个动效不变。过渡压到 0.01ms 而非删除,
  `transitionend` 仍会触发。
- **复盘曲线 canvas 无文字替代**。补 `role="img"` 与说明,接到下方本就是文字的失着列表。

### 评估后撤回的一项

原计划把 **难度 × 思考** 并成一条单调档位(理由:困难·深 3500ms > 极限·快 2500ms,时间阶梯
交叉)。实测撤回——前提"棋力是时间的单调函数"不成立:极限不只给更多时间,还改搜索档
(`vctDepth` 8→10、`maxDepth` 12→14)。两轮各 8 个真正进入搜索的局面,**每加一档时间约
2–3/8 的着法改变**,这个旋钮在做事。

  往顶栏塞按钮,而是删常驻提示段落与多余的 `收起` 按钮、`清除存档` 并入存档弹层:
  **1002 → 856px**,960×900 与 1440×900 下五个入口全部免滚动。

另加 `role="status"` 三处播报,以及一条新闸门(见下)。

### 自伤与闸门

删 `收起` 按钮时留下了无守卫的 `getElementById("collapse").onclick`,它在**初始化中**抛错,
其后所有事件绑定全部没绑上——界面照画,看着正常,只是什么都不响应。交叉回归的
`page.__errors` 断言跑一次就抓得到,但这类错误值得更早更便宜地点名:单测新增闸门,
`src/web/js/` 中任何无守卫的 `getElementById("x").`,`x` 必须存在于 `index.html`。

交叉回归新增三条界面闸门(对比度含透明度合成 / Tab 可达性 / 折叠线),三条都做过反证。

## v1.31.0 · 上一版内容

三项都是已发布功能的实测缺陷,不是新功能。

- **电脑不再每盘下同一局**。同一开局重复 8 局,困难档只走出 1 盘棋(普通 3 盘);
  真机预算下同一局面连测 5 次应手逐字相同。改法不是「在分数接近的着法里挑」——那是拿棋力
  换花样——而是**用局面已有的对称性**取等价着法:棋盘翻转后局面不变,翻转后的应手就是同一手
  棋换个镜像坐标。困难 1 → 5 盘不同,普通 3 → 6;arena 对 v1.30.0 净 0,强度基线不变。
- **复盘曲线原本是贴顶的平线**。`tanh(raw/1200)` 在第 7 手就恒等 1.000000,91 手里 90 手的
  逐手跌幅恰好为 0;失着判据一次都没触发,每局只报「输掉的那一手」。曲线改对数压缩(活三读
  0.60 而非 0.97),判据改为「对手应手之后」再比。每局失着 1 → 平均 4.5 处,首个比终局提前
  中位 21 手,上限 8 处。
- **全部数据可备份**。六个存储键一次导出为 JSON,恢复前校验 + 确认,整体替换。此前只有棋谱
  导出(一次一局),统计/打卡/练习进度完全没有出口。

## 这套回归能证明什么,不能证明什么

v1.38 之前,这份路线图和历次发布说明里的像素数字都被当成「关于发布版应用」的事实在陈述。
它们不是。两条边界必须记在这里,因为它们不会自己浮出来:

**引擎不同。** 交叉回归跑在 Playwright + Chromium;应用在 macOS 跑 WKWebView、在 Windows
跑 WebView2。**canvas 2D 的几何与合成是规范定义的**(棋子半径、格距、alpha 叠加、对比度算术),
那部分结论跨引擎成立。**UA 默认样式、焦点环、滚动条、以及任何「某个 CSS 特性存在与否」的
问题,这套回归结构上看不见** —— color-mix 那 37 处缺兜底能躺 28 个版本,就是这个盲区。

**字体不同。** 容器里渲染中文落到 **WenQuanYi Zen Hei**(闸门 X 钉住了这一点),而 macOS 装
苹方、Windows 装微软雅黑,两个平台都没有它。所以**任何文字的绝对像素值 —— 换行数、元素高度、
弹层高度 —— 只是那个字体下的读数**,不是对发布版的断言。跨字体成立的是「有余量」这类性质,
闸门 W 把字号推到 125% 去证它。

## 验收口径

- 单测全绿(含 i18n 四道闸、worker bundle 闸、版本号闸、对称变化闸、复盘曲线闸、备份闸、
  引擎下限两道闸);交叉回归全绿;每日/练习 8/8;强度基线不变。
- **新用 CSS 特性前**先问它在 WebKit 上的下限:能降级的加前置兜底或 `-webkit-` 前缀,
  两道单测闸门会强制这一点;不能降级的写进本节。
