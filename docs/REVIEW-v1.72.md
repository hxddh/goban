## 挖出来的 bug（v1.72 上复现过）

| # | 现象 | 原因 |
|---|---|---|
| B8 | 从「记录」打开一局**进行中**的棋，接着下完：「最近对局」里变成**两条**——新的「黑胜 9 手」，外加原来那条「进行中 3 手」 | 下完时总是新添一条，不认得「这一局本来就在库里」。v1.72 把旧命名存档迁成「进行中」条目后，这条路径人人都可能走到 |
| B9 | 打开**进行中**的一局，弹「已打开复盘 · 侧栏里有关键手」，侧栏复盘面板也跟着展开 | 打开旧局一律按「复盘一盘下完的棋」处理；没下完的棋应当是「接着下」 |

其余探测都正常：「记录」弹层切英文后没有残留中文；侧栏开着缩到 760 会正确变成抽屉加遮罩；双人终局 → 悔棋 → 再赢，
战绩和最近对局都只记一次。

## 看到的（此刻用不上、却还在）

1. **终局后顶栏的「提示」是灰的**——棋已经下完，它永远点不了。
2. **在最新一手时，翻页的「回到最新」「下一手」都是灰的**——对局中绝大多数时间都在最新一手，这两个灰按钮就一直在。
3. **对局中「新局」是高亮的主按钮**——下到一半，最醒目的动作是「放弃这一局」。它该在一局结束时才是主角。
4. **终局卡的关键一句会断在不该断的地方**：「漏防·被反 / 杀」，一个字掉到第二行。

## 这一版（v1.73）

1. **修 B8**：打开库里一局接着下完，更新原来那一条（结果、手数、用时），不另添一条。
2. **修 B9**：打开进行中的一局就是「接着下」：不展开复盘面板，提示条写「接着下」。下完的局照旧以复盘打开。
3. **终局不显示「提示」**；**在最新一手时不显示「回到最新」「下一手」**（位置保留，看旧手时原位出现，不跳）。
4. **「新局」只在一局结束后是主按钮**，对局中与悔棋、提示同级。
5. **终局卡与复盘解释的文字按词均衡换行**（`text-wrap: balance`），不再单字掉行。
