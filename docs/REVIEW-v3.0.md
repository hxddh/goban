# v3.0 之后：v3.1 —— 对手刚好

评估日期：2026-10-17。基准：main（v3.0.0）。重心仍是对弈：简洁、快速、优雅。

## 方法

1. **先查 v3.0 自己有没有毛病。** 新加的时序最容易藏边角问题，逐条试了：
   - 赢后那一拍里悔棋、按 N、点棋盘；
   - 电脑等待那 0.6 秒里悔棋；
   - 「轮流」下的「再来一局」；
   - 键盘翻看时时间线的显隐；
   - 练习里的时间线；
   - 练习本、日间两套主题和英文界面下「赢的那一刻」与终局卡。
2. **再看「下棋」这条路上还差什么。** 只看对弈，复用 v3.0 评估里那两个模仿人的对手与档位实测。

## v3.0 自查：没有发现问题

| 情形 | 结果 |
|---|---|
| 赢后 0.3 秒内悔棋 | 终局卡不再冒出来，回到对局中 ✓ |
| 赢后 0.3 秒内按 N | 直接新局，终局卡不冒出来 ✓ |
| 赢后那一拍里点棋盘 | 不落子，0.9 秒后终局卡照常进来 ✓ |
| 电脑等待时悔棋 | 取消电脑这一手，退回人的上一手 ✓ |
| 「轮流」时点「再来一局」 | 换色；电脑执黑时 0.6 秒后自己先下 ✓ |
| ← 翻看 / End 回到最新 | 时间线出现 / 收起 ✓ |
| 练习本、日间主题，英文界面 | 五子依次浮出、细环、终局卡都正常 ✓ |

唯一看得出的瑕疵：英文终局卡里「Replay from move 8」放不进半行，次要按钮各占一整行，卡片比中文高一截。

## 结论先说

v3.0 把一来一往的节奏做对了。剩下最影响对弈的，是**对手合不合适**：
- 新用户一上来就碰到一堵墙；
- 下得好了，也没有任何东西告诉你该往上走。

## 一、新用户一上来对的是普通

- 新装的应用，默认难度是**普通**（`session.js` 的默认偏好）。
- 按 v3.0 的实测：

| | 新手胜 | 会下的新手胜 |
|---|---|---|
| 入门（v3.0） | 50 / 100 | 54 / 100 |
| 普通 | **0 / 100** | **0 / 100** |

（「新手」只会挡冲四、延长自己的线；「会下的新手」还会挡活三、走活四，但两者都不会主动做四三。真人对普通不会是零胜，但第一次打开的人，前几盘多半是一直输。）

第一次下棋的体验，决定了还会不会有第二次。

## 二、下得好了，没有人告诉你

- v2.0 起按难度分行的战绩表退役了，「对局」里只有一行总的汇总。**哪一档赢了几盘，界面上看不到。**
- 想换难度：新局 → 选难度 → 开始，**3 次点击**，而且要自己想到去换。
- 档与档之间的台阶不小（入门 → 普通 +307，普通 → 困难 +172）。在入门连赢好几盘的人，不知道自己该上普通了；在普通连输的人，也不知道该退回入门。

## 三、外观不跟系统（上一轮记在后续候选）

应用不读系统的浅色 / 深色。新用户永远是「木」（深色）；浅色模式的 Mac 上只有这个窗口是黑的。「日」主题已经是一套完整的浅色界面。

## 四、落子声

仍是合成的。v3.0 没找到能放心商用的录音。你如果能录一段（黑白各落几子，手机就行），这一版就能换上。

## 这一版（v3.1）：对手刚好

| 项 | 改什么 | 量什么 |
|---|---|---|
| 新用户从入门开始 | 默认难度 普通 → **入门** | 第一次打开，座位写「电脑 入门」。已有偏好的老用户不动 |
| 往上走、往下走 | 同一档**连赢 3 盘**，终局卡多一行「连赢 3 盘 · 试试普通」和一个按钮「用普通再来一局」；**连输 3 盘**同理建议退一档。一键换档开局 | 换难度开下一盘 3 次点击 → 1 次；只是建议，不自动换；入门不再往下、极限不再往上 |
| 跟随系统外观 | 主题加「自动」，新用户默认：浅色用「日」，深色用「木」，系统切换时立刻跟着换 | 模拟浅色 / 深色；老用户选过的主题不动 |
| 英文终局卡 | 次要按钮并成一行（「Replay from move 8」缩成「Replay move 8」） | 英文终局卡与中文同高（±1 行） |

### 为什么是「连 3 盘」

- 一盘的输赢运气成分大：v3.0 实测困难对普通，同一开局正反两盘，24 个配对里 13 个是一胜一负。
- 连 3 盘是一个人能感觉到的「最近总是赢 / 总是输」。
- 门槛再高，建议来得太晚；再低，建议会来回跳。
- 档与档之间台阶不小，所以只建议、不自动换，留给玩家自己决定。

### 验收（闸门）

新闸门 `test-surface` S21，每一条在 v3.0 上失败：
- 第一次打开时难度是入门；
- 同一档连赢 3 盘后，终局卡有「试试普通」和一键按钮，点了直接用普通开局；
- 连输 3 盘建议退一档；
- 入门连输、极限连赢不再建议；
- 「自动」主题跟随模拟的浅色 / 深色；
- 英文终局卡不高于中文。

现有闸门照旧全部通过；默认难度变了，读默认值的旧闸门照惯例逐条改写并列出。

### 工作量

都不大。
- 连胜 / 连败从对局库按「同一模式、同一难度、最近连续」算，库里本来就存了难度。
- 建议是终局卡上多一行、多一个按钮。
- 外观只动主题选择，四套主题本身不动。

### 需要你决定的

1. **默认从入门开始？** 建议**是**。老用户不受影响。
2. **连几盘建议换档？** 建议**3 盘**；可选 2（更灵敏）/ 5（更稳）。
3. **跟随系统外观**这一版做不做？建议**做**，代价很小。
4. **落子声**：有录音就这一版换；没有就继续顺延。
