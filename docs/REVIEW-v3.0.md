# v3.0 之后：v3.1 —— 想得快

评估日期：2026-10-17。基准：main（v3.0.0）。按你的要求，**只看对弈本身**：盘上的规则、对手的每一手、下一盘棋的过程。难度建议、主题外观这类「棋局之外」的东西，这一稿全部拿掉。

## 方法

1. **v3.0 自查**：把新加的时序逐条试了一遍。
2. **对手的每一手**：
   - 用档与档对局、两个模仿人的对手，量了这几样：电脑的落点自然不自然；局面已定之后还要下几手；自由与禁手两种规则下各档是否站得住；执黑执白差多少。
   - 每一档每一手**等了多久**。
3. **引擎本身**：做了 CPU 剖析，看时间花在哪；又改了一个原型，量能快多少，并核对改完后每一手是否与原来**完全相同**。

除了禁手下的极限，这几样都不需要改。

## 问题一：禁手规则下，极限不比困难强

- 自由规则下，极限（时间用满）对困难 +137，p = 0.006，说明里「实测明显强于困难」成立。
- **禁手规则下 24 盘 12 : 12**（执黑赢 18 盘）：多给的时间没有变成棋力。
- 原因在引擎的注释里写着：禁手档下，只有连杀的第一手查是否禁手，后面几手仍按自由式算。搜得越深，算进去的「黑棋其实走不了的棋」越多，多出来的时间花在了不存在的变化上。

修好要让搜索里的每一手黑棋都懂禁手，是引擎的一块大改，需要单独评估（速度会掉多少、强度能涨多少）。这一版先**照实写**：极限的说明里加上「自由规则下」，禁手档下不承诺强于困难。

## 问题二：极限要等 5 秒

v3.0 让极限把时间用满，换来了对困难显著更强（+137，p = 0.006）。代价实测出来了：

| | 中位数 | 75% | 90% | 最长 | 超过 3 秒的手 |
|---|---|---|---|---|---|
| 困难 | 0.47s | 1.28s | 1.94s | 2.0s | 0 |
| **极限** | **5.0s** | **5.0s** | **5.0s** | 5.0s | **66 / 123** |

极限**一半以上的手要等满 5 秒**。下极限的人，每一手都在等。这和「快速」正相反。

## 引擎的时间花在哪

CPU 剖析（困难 / 极限的搜索）：

| 函数 | 占比 | 做什么 |
|---|---|---|
| `genMoves` | **44%** | 每个节点把 225 个点扫一遍，把所有候选（常有 60 个以上）全部排序，**然后只留前 8–14 个** |
| `make` / `unmake` | 40% | 落子 / 提子时更新周围的棋型；提子时把周围 32 个点的棋型**重新算一遍**，而不是还原落子前的值 |
| 其余 | 16% | 搜索本身、置换表、评估 |

### 原型：只排出要用的前几个

把 `genMoves` 里「全部排序再截断」改成「只挑出前 k 个」，同分时的先后顺序与原来完全一致。核对与实测：

| | 结果 |
|---|---|
| 同样的节点数下，每一手是否相同 | **223 / 223 完全相同** |
| 同样的节点数下，用时 | 37.1 秒 → 24.0 秒，**快 1.55 倍** |

每一手完全相同，就等于**棋力一点没变**，只是更快算完。`unmake` 改成「还原落子前的值」还有余量，估计合起来能到 2 倍左右。这一部分要做完才知道，所以下面只按已经证实的 1.5 倍来算。

### 快出来的时间，还给等待

各档原来是按时间定的强弱（入门 0.24 秒、普通 0.4 秒、困难 2 秒、极限 5 秒）。引擎快了以后，**同样的时间会变强**，入门、普通也会跟着变强，打乱 v3.0 刚校准好的阶梯。

所以把每一档的时间按同一个比例缩短，节点数和今天一样多：
- 棋力不变；
- 等得更短。

| | 现在 | 引擎快 1.5 倍、时间同比缩短后（实测） |
|---|---|---|
| 困难 中位数 / 90% / 最长 | 0.47 / 1.94 / 2.0s | 0.08 / 1.05 / 1.3s |
| **极限** 中位数 / 75% / 最长 | **5.0 / 5.0 / 5.0s** | **0.23 / 3.2 / 3.2s** |
| 入门、普通 | 0.24 / 0.4s | 更短，但都在 0.6 秒的落子节奏以内，看不出差别 |

缩短的比例按实测的节点速度定，不是拍脑袋。验收看三样：
1. 每一档每一手的节点数与今天相当；
2. 档与档的配对胜负与 v3.0 不显著不同；
3. 棋力闸门照旧通过。

| 项 | 改什么 | 量什么 |
|---|---|---|
| 引擎快 | `genMoves` 只排前 k 个；`unmake` 还原而不重算 | 同节点数下每一手与 v3.0 **完全相同**（固定局面集）；同节点数用时 ≥ 1.5 倍快 |
| 等得短 | 各档时间按实测速度同比缩短 | 极限中位数 5.0s → ≤ 3.5s、最长 5s → ≤ 3.5s；困难最长 2s → ≤ 1.4s；各档配对胜负与 v3.0 一致（p > 0.05 视为一致）；棋力闸门照旧 |

| 说明照实 | 极限的说明加「自由规则下」 | 禁手档下不再承诺强于困难 |

棋局之外什么都不动。

### 看了、这版不做的

- **认输**：局面已定后平均只再下 2–3 个必挡，最多 9 个。认输要在棋盘旁加一个按钮，换来的不多。
- **执黑优势**：自由规则下颜色压过一档，这是自由五子棋本身的性质。已经有禁手、swap2 可选，「轮流」在困难、极限下是默认，新局卡片也写了「执白大约难一档」。不另加让子。
- **落子声换录音**：仍然没有可靠的来源。你给录音就换，不进这一版的计划。
- 上一稿里的「默认入门」「连赢建议换档」「跟随系统外观」：属于棋局之外，按你的意见拿掉。

### 需要你决定的

1. **快出来的时间怎么用？**
   - 建议**还给等待**：棋力不变，各档都更快，极限从「每手等 5 秒」变成大多数手 3 秒以内。
   - 另一个选择是保持时间不变，让每一档都更强。那样 v3.0 刚校准好的阶梯就要重新量一遍。
2. **禁手下的极限**：这一版只把说明写实（建议），还是把「引擎搜索懂禁手」也放进这一版？后者是大改，我建议下一版单独评估。
3. **版本号**：建议 **3.1.0**。
