## 这一版：侧栏只留下棋要用的

方法：Chromium 1280×800 逐个状态截图，数每个状态下看得见、点得到的控件（棋谱里的每一手不计）。

| 状态 | 可点控件 | 其中「此刻用不上」的 |
|---|---|---|
| 首次打开 | 24 | 导入、粘贴（悬在首次提示下面，孤零零两个字） |
| 对局中 | 24 | 复制、导出、导入、粘贴；「每日」与「练习」是同一件事的两扇门 |
| 终局 | 33 | 同上 |

另有三处**同一信息说两遍**：顶栏「6/6」与侧栏「6 / 6」；信息行「普通」与下面的难度选择；信息行的
「已存 09-29 09:25」（自动保存本该是看不见的）。

### 改三件

1. **棋谱文件挪进「存档」**：复制、导出、导入、粘贴四个按钮离开侧栏，进「存档」弹层——那里本来就管
   备份 / 恢复，是「文件」的家。侧栏的「棋谱」区只剩棋谱本身和翻页。
2. **「每日」并进「练习」**：练习弹层打开时，今天的 5 题放在最前面；到期数的徽标挪到「练习」上。
   首次提示里的「先做今天的 5 道题」照旧。学习区从三个按钮变两个：复盘 · 练习。
3. **一件信息只说一遍**：去掉顶栏的手数（侧栏有）、信息行的「已存 …」、以及人机对局时信息行里的档名
   （下面的难度选择已经标着它）。

不动的：棋盘、配色、对局流程、终局卡、设置弹层、引擎。

### 验收（闸门）

- 可点控件：首次打开 **24 → ≤ 21**；对局中 **24 → ≤ 19**；
- 每一样挪走的功能都还在，而且**两步之内**能到（存档 → 复制 / 导出 / 导入 / 粘贴；练习 → 每日），闸门逐个点一遍；
- 同一信息不重复：顶栏不出现手数，信息行不出现「已存」；
- 旧有的全部测试（test-game / cross / surface / daily / loop / strength）照旧通过。

### 需要你决定的

- **把「每日」并进「练习」**：每天打卡的人要多点一下（点「练习」，今天的题就在最上面）。我的判断是值得：
  两个按钮做同一件事，比多一次点击更让人困惑。
