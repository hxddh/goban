## 一、结论

v1.63 的方向是对的，完成度也高：「下一局 → 找到自己的错 → 不看答案重下 → 次日独立做对」这条路
第一次真正连成一条线，每一段都有闸门，证据分层诚实地写在界面上。**但离「顶级」还差两件事，而且
这两件事不是「再加一个功能」能补上的：**

1. **接缝处不牢。** 这一轮找到 9 个正确性问题，**6 个出在模式之间的切换上**：对局 / 复盘 / 重下 /
   导入 / 从对局库打开旧局。每一个都是「某个状态没跟着走」——库里的旧局被悔棋删掉、导入的棋谱
   改掉了设置里的规则、重下能退过失着那一手……它们已在 **v1.63.1** 修掉，各配一道闸门（在 v1.63.0
   上逐条跑过，都报）。但根还在：`app.js` 2885 行里，「现在处于哪种模式」散落在 `retry`、
   `importPaused`、`swap2`、`endCardOn`、`aiThinking`、`hintBusy`、`statsRecordedGen`、
   `lastArchiveId` 八个变量里，没有一处说得清全貌。下一个加进来的模式会再撞一遍。
2. **面太多。** 学习是这款产品的定位，但它的五个入口是侧栏最底下一排小字（存档 复盘 练习 每日
   统计）；同一件事「复盘」有两个面（弹层里有曲线和列表，侧栏里有芯片和解释）；一共 7 种弹层。
   顶级产品的优雅来自**每件事只有一个地方**，而不是每个地方都做得精致。

**所以建议 v1.64 做「收口」，而不是引擎 2.0**：先把模式收成一台显式的状态机、把复盘收成一个面、
把学习入口抬到与「对局」同级；引擎 2.0 ②③ 排到 v1.65。理由见第四节。

## 二、v1.63 做得好的（下一版不要动）

- **证据分层说实话。** 可证明 / 引擎比较 / 局势波动三档，界面上字面写出来；第二遍引擎比较会撤掉
  引擎也会走的「失着」。这是同类产品里少见的克制。
- **终局卡不弹层。** 一局下完，棋盘保持可见，侧栏顶部一句结果、一个值得记住的地方、一个主行动。
  这是对的形状。
- **重下关键一手保留原局。** 原局一手不改，重下的线作为变着挂回去，导出 SGF 能看到。
- **掌握的定义。** 「隔一次到期复习再独立答对」才算掌握，用了提示或看过答案不算。定义严格、可解释。
- **闸门文化。** 每条承诺都有反证。这一轮修复沿用了同样的做法。

### 3.2 留给 v1.64 的（按对「顶级」的影响排序）

**P0 · 结构**

- **模式没有一个名字。** 见第一节。症状：v1.63 的 9 个问题里 6 个是接缝；`serialize()` /
  `applySnapshot()` 要为每种模式单独记得带什么、不带什么（`statsEndedAt`、`retry`、`archiveId`
  各是一个特例）。
- **「偏好」与「这一局」共用变量，规则只是其中之一。** v1.63.1 把规则拆成了偏好（`prefRule`）与
  这一局（`ruleSet` / `openingRule`）。但 `mode` / `difficulty` / `humanColor` 仍是同一种写法：
  从对局库打开一局双人旧局，或进入重下（强制人机、改执子），之后任何一次 `saveSettings()`（比如切
  主题）都会把这一局的值写成偏好，下一次「新局」就按它开。这一版没有逐个补——逐个补正是接缝越补
  越多的原因——而是留给 A 项一次收掉：偏好一张表，这一局一张表，`reset()` 只从偏好开局。

**P1 · 信息架构**

- **学习入口埋在最底下。** 侧栏底部一排 `var(--fs-ui)` 小字，与「复制 / 导出」同一视觉层级；
  每日的到期数只是字后面的一个数字。产品定位是学习，入口却是整个界面里最不显眼的一行。
- **复盘有两个面。** 弹层（曲线 + 失着列表 + 导出）与侧栏常驻面板（芯片 + 四句解释 + 重下 / 练 /
  推演）。用户得先知道「弹层看全局、侧栏看一手」这条隐含分工。v1.63 已把跳转后的解释搬进侧栏，
  剩下的一步是把曲线也搬进去，弹层就可以退役。
- **同一个数写两遍。** 顶栏 `10/10 · 00:16`，侧栏又是 `10 手 · 00:16`。顶栏的 `0/0` 是开发者读法。
- **7 种弹层。** 确认 / 设置 / 帮助 / 存档 / 练习 / 统计 / 复盘。其中存档、统计、复盘是「看过去」，
  练习、每日是「做题」——两类各收成一个空间，弹层只留给确认与设置。

**P1 · 复盘的可信度表达**

- **「局势波动」档仍然进列表、进终局卡的「其他关键手」。** 实测一局 10 手的人机局，第 3 手被标成
  「评分下滑 · 局势波动」。这一档的依据是静态评估，v1.63 自己也承认它不是结论。顶级的做法是
  **默认折叠**：「另有 1 处局势波动（未经引擎确认）」，展开才列。终局卡只从可证明与引擎比较里挑。
- **曲线没有刻度与含义。** 「黑上 · 白下」写在标题里，零线与幅度都没有标，读不出「差多少」。
- **文案是术语。** 「漏防·被反杀」「替代：挡在 F12（或抢先成五）」——对象是普通玩家，应当是
  一句人话：「白已经四连，这一手要挡在 F12」。

**P2 · 初见**

- **首启没有任何引导。** 一张空棋盘、「黑棋落子」。第一次打开的人不知道默认是人机普通档，也不知道
  练习与每日存在。一句话、一次性、可跳过的「今天想做什么：下一局 / 做 5 道题」就够。
- **macOS 未公证、Windows 未签名。** README 用了整整一节教用户绕过 Gatekeeper。这是离「顶级」最远的
  一步，但它要的是 Apple Developer ID 与代码签名证书——**这是维护者的决定，不是一版能做的事**，
  记在这里只为不让它被忘掉。

**P2 · 迁移**

- 老用户升级后「已掌握」归零（定义变严了，旧进度里没有到期复习的记录）。可把 v1.62 的「答对且从未
  答错」折算成一次独立答对（`streak = 1`，`due = 今天`）——这样旧题进入到期队列，而不是凭空变成掌握。

## 四、v1.64 建议：收口 —— 一件事只在一个地方

### 为什么不是引擎 2.0

ROADMAP 把「引擎 2.0 ②③」（搜索内认禁手、先后手调平）排为下一步，理由成立：教练的可信度上限
是引擎棋力。但现在做它有两个问题：

1. **它会落在最不牢的地方上。** 引擎 2.0 要改的是 `aiMove` 的内部；而这一轮找到的最严重的复盘问题
   （#4）不是引擎不够强，是**引擎的结果被接缝吃掉了**。在接缝收口之前提升棋力，用户感受不到。
2. **学习入口的可达性比棋力更早卡住用户。** 窄窗口看不到终局卡（#5）比「引擎比较用的是 500ms
   首选而不是深度求解」更早、更普遍地让闭环失效。

### 范围（四项，每项一句话验收）

| # | 做什么 | 验收（闸门） |
|---|---|---|
| A | **会话状态机**：`session.kind ∈ { play, review, retry, import }`，每种 kind 声明它的规则来源、悔棋下限、是否计统计、是否进对局库、终局卡与复盘面板的可见性；偏好（模式 / 难度 / 执子 / 规则）与这一局分成两张表；`serialize` / `applySnapshot` / `undo` / `reset` 只读这两张表 | 一张 kind × 操作 的真值表单测（悔棋 / 新局 / 导入 / 打开旧局 / 重下 / 切语言 / 读存档 / 重启），v1.63.1 的六段 loop 闸门原样通过；`app.js` 里那八个变量有一半被删掉 |
| B | **复盘只有一个面**：曲线（带零线与幅度刻度）、失着列表（局势波动默认折叠）、当前一手的解释、重下 / 练 / 推演 / 导出，全部在侧栏；复盘弹层退役 | 复盘相关的弹层数 0；1280×720 与 960×620 两档下复盘面板不滚动即可看到曲线与第一条失着；局势波动档不进终局卡（反证：只有软失着的对局，终局卡说「没有检出明显失着」） |
| C | **学习与对局同级**：侧栏顶部一行三段 `对局 · 复盘 · 练习`，每日与到期数挂在「练习」上；存档与统计并入「复盘」空间的「过去的对局」 | 顶层入口数 3；首屏不滚动即可点到练习；到期数以徽标呈现（视觉层级高于底部链接）；5 秒内找到每日挑战（真人测试，见下） |
| D | **初见一句话**：首次启动一次性、可跳过的选择「下一局 / 做 5 道题」，选完记住，不再出现 | 首启出现、第二次不出现、跳过即消失；读屏可达 |

顺手的两条小项：顶栏去掉与侧栏重复的手数与时钟（或反过来，只留一处）；旧进度的掌握折算（3.2 P2）。

### 明确不做

- 引擎 2.0 ②③ → **v1.65**，范围照 ROADMAP 原文。
- 新题型、新主题、新规则。
- 公证 / 签名（等维护者决定）。

### 如何证明它是「收口」而不是「又一版功能」

沿用 v1.63 评审里「如何证明质变」的那套无指导测试，但换成三个问题，5–8 人，每人 10 分钟：

1. 下完一局后，**不看提示**，能否在 30 秒内重下自己输掉的那一手？（测终局卡 + 可达性）
2. 能否在 5 秒内开始今天的每日挑战？（测入口层级）
3. 看完一局复盘，能否说出「哪一手是确定的错、哪一手只是可能不好」？（测证据分层的表达）

三题的通过率比 v1.63 高，才算这一版成立。
