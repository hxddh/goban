## 为什么这一版不再「减一个按钮」

v1.68 到 v1.73 连续六版，每版从同一张侧栏里拿掉一两样，控件从 24 降到 13。能减的都减了，剩下的问题是
**侧栏这个结构本身**：

1. **同一件事说两遍。** 顶栏写「白棋胜」，侧栏第一行又是「黑 你 · 白 电脑」；顶栏「新局」，侧栏「难度」
   在对局中也常驻，改了只对下一局生效。
2. **看棋要在两处之间来回。** 棋在左边，棋谱、翻页、复盘曲线、失着解释都在右边 280px 的窄条里。
   复盘时眼睛要在「棋盘上的那一手」和「侧栏最底下的解释」之间来回跳。
3. **复盘被挤在最下面。** 顺序是棋谱 → 一排翻页 → 复盘面板。1280×720 下复盘面板从 y=440 才开始，
   上面是一整块手数列表。
4. **窄窗口反而最好看。** 760 宽时侧栏收起，只剩顶栏和棋盘。截图里最干净、最像一件作品的，
   是没有侧栏的那一张。

所以这一版不再修剪侧栏，而是**把它去掉**：棋盘就是界面。

## 这一版（v1.74）：只剩一块棋盘

1. **去掉侧栏。** 所有宽度都是同一个布局：顶栏 + 居中的棋盘。侧栏开关按钮随之去掉，窄窗口不再有抽屉和遮罩。
2. **顶栏是唯一的操作区**：左边一句状态（「轮到你 · 执黑 · 对普通」/「你输了 · 白棋五连」），把侧栏的
   对阵行并进来；右边 **悔棋 · 提示 · 新局 · ⋯**。
3. **一条时间线代替棋谱**：棋盘下方一条细线，拖动、点击、←/→、Home/End 都能翻；悬停显示「第 8 手 H8」。
   替掉的是**手数列表、三个翻页按钮和「12 / 12」**这三样。空棋盘时不出现。
4. **复盘时，时间线就是局势曲线**：同一条线长高成曲线，失着是线上的红点，点红点跳到那一手。
   解释以一张卡片出现在棋盘下方，**打开复盘时直接显示最关键那一手的解释**（修 B11）。复盘不再是一个面板，
   而是棋盘的一个状态；「重下这一手 · 练这一手 · 推演」在卡片里。
5. **终局卡移到棋盘下方**，和复盘卡同一个位置、同一种样子：一句结果、值得记住的一手、「重下第 N 手」「复盘」。
   关键一句按「第 11 手 · 黑 · 漏防，被反杀」整体排，数字和「手」不拆开（修 B10）。
6. **「新局」打开一张小卡片**：对手（电脑 / 双人）· 难度 · 执子（困难、极限另有思考时长），「开始」或回车。
   上一局的选择默认选好，所以大多数时候是「新局 → 回车」。**模式、难度、执子三行从主界面上消失。**
   第一次打开不弹这张卡：直接点棋盘就用默认设置开局。
7. **「⋯」收起其余入口**：练习（到期题数的徽标挂在「⋯」上）· 对局记录 · 设置 · 快捷键。
   「复盘」入口不单列：终局卡里有，对局中按 R 或点时间线也能进。

不动的：棋盘、棋子、配色、四套主题、引擎、规则、练习弹层、记录弹层、设置弹层、所有快捷键。

### 需要你决定的

1. **手数列表整个去掉？** 时间线悬停能看到每一手的坐标，SGF 复制 / 导出都还在「对局记录」里。
   我的判断是去掉——它是侧栏里最大的一块，而逐手坐标只有少数人会看。你想留，可以放进「对局记录」里按局展开。
2. **练习要不要也搬到主棋盘上？** 现在练习弹层里有一块自己的小棋盘，和主棋盘并存。搬过来会更彻底
   （全应用只有一块棋盘），但练习的流程（题目切换、看答案、离开时回到对局）要重做一遍，这一版风险翻倍。
   我的判断是**这一版不动**，留到下一版单独做。

### 工作量与风险

这是 v1.64 以来最大的一次界面改动：`index.html` 的侧栏整块重写，`app.js` 等处约 70 处读写侧栏元素的地方要改，
`test-cross` / `test-surface` / `test-loop` 里约 20 条碰到侧栏的测试要退役或改写。引擎、规则、存储、练习都不碰。
预计一个版本做完；闸门照例在旧代码上先失败。
