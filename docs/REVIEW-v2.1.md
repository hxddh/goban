# v2.1 之后：v3.0 —— 一来一往

评估日期：2026-10-14。基准：main（v2.1.0）。要求：大版本，质变。**重心是对弈**：这个产品的核心是陪用户下棋，围绕对弈体验去质变；保持简洁、快速、优雅。

## 方法

只看「下棋」这一条路：打开 → 落第一子 → 一来一往 → 分出胜负 → 下一盘。每一步量能量的：

- 你落子后，电脑的子隔多久出现（入门 / 普通 / 困难 / 极限）；
- 同样的着法下三盘，电脑是不是每次走一样；
- 点下去到子出现，主线程做了多少事；落子动画每一帧画了什么；
- 连成五到终局卡出现隔多久；终局卡的主按钮是什么；下完到下一盘要点几下；
- 下棋时棋盘之外看得见什么。

说明：容器里是软件渲染、没有 GPU，帧率数字不代表 Mac 上的观感，下文只用它说明「画了什么、画了几次」这类结构上的事实。

## 结论先说

棋力、规则、变化都已经扎实：
- 四档棋力有闸门；
- 同样的着法连下三盘，三档电脑的应手每次都不一样，不会背谱。

差的是**节奏和手感**，就是「坐在对面下棋」的那种感觉：

1. **对面像没有人。** 入门、普通 200–440ms 就落子：你的手还没抬起，它的子已经在了。
2. **落子那一下不够干脆。** 落子动画的每一帧都把整块棋盘连同所有棋子重画一遍；落子声是合成的。
3. **赢了没有那一刻。** 连成五 19ms 后终局卡就弹出来，五子还没看清，卡片已经在讲道理。
4. **下完一盘，下一盘要找。** 终局卡的主按钮是「从第 N 手重下」，不是「再来一局」；顶栏「新局」打开的是设置面板，还要再点「开始」。
5. **棋盘之外还有东西在动。** 一个一直在跳的计时器，一条下棋时用不上的时间线。

对手本身也量了（第七节）。困难确实显著强于普通，但有三处不对：
- 入门对真正的新手偏难（新手只赢 26%）；
- 入门和普通之间是一道墙（+307，会挡不会杀的人一盘也赢不了普通）；
- 极限现在**不比困难强**（+44，p = 0.23），说明里写的「明显强于困难」不成立。

三处都先试了修法，数字在第七节。

v3.0 把这五件事做对，再把对手的阶梯理顺：**一来一往有节奏，落子干脆，赢有赢的样子，下完一键再来，下棋时眼里只有棋。**

## 一、对面像没有人

实测：你落子后，电脑那一子出现的时间（开局三手）。

| 难度 | 现在 |
|---|---|
| 入门 | 198–232ms |
| 普通 | 242–443ms |
| 困难 | 332–1783ms |
| 极限 | 310–4610ms |

入门、普通几乎和你的子同时落下，你的眼睛还停在自己那一子上，常常没注意到它下在哪。电脑那一子和你的用的是同一个 120ms 小动画，最后一手只有一个小圆点。

### 这一版

- **电脑最短 600ms 才落子**（入门、普通；困难、极限通常本来就超过）。这段时间座位里的三个点照常在动。算法的时间预算一毫秒不动，棋力不变，只是算完了等一等。
- **电脑那一子落得让你看见**：比你的子多一点「落定」的过程（约 250ms，轻轻放下），最后一手的标记在它落定时出现。你的子仍然是即点即现。
- 双人对局两边都是人，不加等待。

## 二、落子那一下

- **点下到子出现**：一次点击里同步做完的事 16–64ms（落子、存档、刷新界面、画棋盘）。
- **落子动画**：在 140ms 里每一帧都**整块重画棋盘**：底色、网格、星位、全部棋子的渐变和阴影，只为让新落的那一子从 0.88 倍放大到 1 倍。棋子越多，每帧越重。大窗口下这一段在容器里有掉帧（上面说过，帧率数字只作参考）。
- **落子声**：振荡器加噪声合成，听得出是合成的。

### 这一版

- **新落的子单独一层画**：棋盘和其余棋子画好就缓存，动画只画那一子。点下去的那一帧子就在。存档、刷新侧边这些不影响画面的事挪到这一帧之后做。
- **落子声换真实录音**（见文末待定 3）：蛤碁石落在木盘上的一声，黑白两子略有不同。

## 三、赢了没有那一刻

连成五之后：
- 19ms 终局卡就出来了；
- 同时一根红线穿过五颗子，五颗子各套一个红圈；
- 胜负音乐响起。

三样东西挤在同一瞬间，最该看的那五颗子反而被线和圈压着。

### 这一版

- **五子先亮**：连成五的那五颗子发一圈柔和的光，一颗接一颗，约 0.5 秒。不再画红线和红圈。
- **停一拍，卡片再进来**：约 0.8 秒后终局卡从旁边滑入。这一拍里棋盘就是整个画面。
- 输了也一样：亮的是电脑那五颗，颜色收敛，不庆祝。

## 四、下完一盘，下一盘要找

| 项 | 现在 |
|---|---|
| 终局卡主按钮 | 「从第 N 手重下」（双人对局也是） |
| 顶栏「新局」 | 打开设置面板，还要再点「开始」 |
| 下完到下一盘 | **2 次点击**（或按 N，没人知道） |

### 这一版

- 终局卡的主按钮换成 **「再来一局」**：同样的设置，一键就开。执子选「轮流」时自动换色。
- 「从第 N 手重下」「看复盘」降为卡片里的次要按钮，功能不变。
- 顶栏「新局」照旧打开设置面板，用来换难度、换规则。
- 下完到下一盘：**1 次点击**。

## 五、下棋时，棋盘之外的东西

下棋时看得见的：
- 两个座位；
- 计时器 `00:05`，每秒跳一次；
- 悔棋 · 提示 · 新局 · ⋯；
- 棋盘下方一条时间线和「6 / 6」。

- **计时器**：这不是计时对局，没有人在跟时间赛跑，它只是一直在跳，分走眼睛。
- **时间线**：翻看前面的手是下完以后、或者想回头看一眼时才用的事。下棋时它一直横在棋盘下面。

### 这一版

- **计时器下棋时不显示**；用时写进终局卡（「用时 3:12」），也照旧记进对局列表。
- **时间线下棋时收起**：鼠标移到棋盘下沿、或按 ← 翻看时才出现；下完一盘、复盘时照常显示。键盘的 ← → Home End 不变。
- 下棋时看得见的就剩：**两个座位、棋盘、悔棋 · 提示 · 新局 · ⋯**。

## 六、顺手修（都在下棋时看得见）

- **坞贴着窗口边**：1280 × 800 下终局卡离窗口右边只有 **6px**，1440 × 900 下 12px，左边却空着近 300px。改为至少 20px。
- **新局面板压着初见卡片**：空盘点「新局」，面板盖在初见卡片上，卡片右边一截露在外面。面板打开时初见卡片让开。
- **输家座位看不清**：终局后变淡的「你」对比度约 **3.2:1**（正文要求 4.5:1）。改为换次要色，不再整颗降透明度。

## 七、对弈引擎：难度合不合理，承诺达不达标

对弈的另一半是对手。三件事都量了：
- 四档之间是不是一级一级地强；
- 每一档说明里写的话做到没有；
- 真实水平的人在每一档面前有没有机会。

### 怎么量

- **档与档**：用仓库里的 `bench-vs-ref`，走发布的档位路由和**发布时限**（普 0.4s / 难 2s / 极 5s，不缩放）。
  - 24 个开局，每个开局正反各下一盘，按配对计分，先手优势在配对内抵消。
  - 带符号检验的 p 值，p < 0.05 才算「显著更强」。
- **「人」**：写了两个模仿人的对手，各下 60–100 盘，黑白各半。
  - **新手**：能成五就成五，对面有冲四就挡，其余只顾延长自己最长的那条线。
  - **会下的新手**：在新手基础上，会走活四，也会挡活三。

  两者都不会主动做四三、双三这样的杀棋。所以它们只能衡量下面两档；它们赢不了的那几档，要靠档与档的对局来看。
- **承诺**：电脑每次面对冲四、活三时，记下它挡没挡。

### 档与档（发布时限）

| | 配对（胜 / 平 / 负） | 逐局 | Elo | p |
|---|---|---|---|---|
| 普通 vs 入门 | 17 / 7 / 0 | 41 : 7 | **+307** | < 0.0001 |
| 困难 vs 普通 | 11 / 13 / 0 | 35 : 13 | **+172** | 0.0005 |
| 极限 vs 困难 | 5 / 17 / 2 | 27 : 20 | **+44** | **0.23，不显著** |

另外，四档之间的每一组对局里，**执黑的赢了约七成**（35/48、36/48）。自由规则下先手的优势，大约等于一整档。

### 「人」在每一档面前

| | 新手胜 | 会下的新手胜 |
|---|---|---|
| 入门 | 26 / 100 | 35 / 100 |
| 普通 | 0 / 60 | 0 / 60 |
| 困难 / 极限 | — | 0 / 20 |

### 每一档的说明，做到没有

| 档 | 说明里写的 | 实测 | |
|---|---|---|---|
| 入门 | 会挡住你的冲四 | 230 / 230 | ✓ |
| 入门 | 常常漏掉活三 | 漏 21–29%，约四次漏一次 | ✗ 是「有时」，不是「常常」 |
| 普通 | 必挡直接威胁 | 冲四 133 / 133，活三 66 / 66 | ✓ |
| 普通 | 每手约 0.4 秒 | 平均 0.22s，最长 0.44s | ✓ |
| 困难 | 每手约 2 秒 | 平均 **0.59s** | ✗ 写多了：v1.68 起想好就落子，平均不到 0.6 秒 |
| 极限 | 实测明显强于困难 | +44，p = 0.23 | ✗ **现在不成立** |
| 极限 | 难局最多算 5–8 秒 | 上限 5 秒 | ✗ 8 秒那一档 v2.0 已退役，文字没改 |

### 结论

1. **入门对真正的新手偏难，说明也不准。** 新手只赢四分之一。说明里写「常常漏掉活三」，实测四次才漏一次。
2. **最大的台阶在入门与普通之间。** +307，比上面两级加起来还多。
   - 普通从不漏挡活三，所以只会挡、不会做杀的人一盘也赢不了（0/60）。
   - 能赢入门三成多的人，到了普通就是 0。
3. **极限现在不比困难强。** v1.68 加了「最佳手稳定就落子」，极限多给的时间大多没用上，平均每手只用 1.3 秒。
   - v1.68 当时在缩短的时限下量到 p = 0.002；今天按发布时限量，p = 0.23。
   - 引擎从 v1.68 起没改过（v1.69 只动了禁手）。是量法变了，结论跟着变了。
4. 困难的「约 2 秒」和极限的「5–8 秒」两句文字都过时了。

### 两个修法，都先试过

**A. 极限把时间用满**：极限不再「想好就停」，困难照旧。

| | 配对 | Elo | p | 平均每手 |
|---|---|---|---|---|
| 极限（用满）vs 困难 | 10 / 13 / 1 | **+137** | **0.006** | 2.2s / 0.6s |

极限重新显著强于困难，代价是每手平均多等约 1 秒，仍远小于 5 秒的上限。

**B. 入门更常漏活三**（漏挡概率 0.3 → 0.5）：

| | 新手胜 | 会下的新手胜 |
|---|---|---|
| 入门（现在） | 26 / 100 | 35 / 100 |
| 入门（0.5） | **50 / 100** | **54 / 100** |

新手对入门五五开，入门的说明「常常漏掉活三」也就成立了。

**但 B 会把下面那道台阶拉得更陡**：普通对新入门 +470 到 +545。所以光改入门不够，普通也得往中间挪。又试了三种普通：

| 候选的普通 | 对新入门 | 困难对它 | 会下的新手胜 |
|---|---|---|---|
| 现在的普通（0.4s） | +545 | +172 | 0 / 100 |
| 普通 0.4s，活三漏挡 12% | +470 | +191 | 6 / 100 |
| 普通 **0.1s** | **+280** | +545 | 0 / 100 |
| 普通 0.04s | +191 | — | — |

只缩时间，台阶就从下面挪到了上面。所以合理的阶梯是**整体往下挪一级**，每一级都是直接对局实测：

| 新的档 | 是什么 | 比下一档强 | p |
|---|---|---|---|
| 入门 | 现在的入门，活三漏挡 0.5 | — | — |
| 普通 | 普通的搜索，每手 0.1s | 入门 +280 | 0.0002 |
| 困难 | **现在的普通**（0.4s） | 普通 +154 | 0.003 |
| 极限 | 困难的搜索、时间用满（修法 A） | 困难 待测（约 1 小时，跑完补上） | — |

这样：
- 新手对入门五五开；
- 每一级都显著强于下一级，台阶在 150–300 之间，不再是一道 +307 的墙加一级量不出来的假台阶；
- 最上面一档比今天的极限更强：用满时间的极限对今天的困难 +137，今天的极限只有 +44。

代价：
- 每一档的名字对应的棋力变了。今天下「困难」的人，v3.0 的「困难」是今天的普通，会觉得变容易了。
- 所以这一项单独列进待定，由你决定。

### 先手

执黑的赢七成，相当于一整档。不另加让子规则（简单）。在新局卡片的执子选项上写一句：执白更难。

## 八、看了、这版不做的

- **复盘在棋盘上画标记**（上一稿的重心）：按你的意见移到后续。复盘的说明靠坐标、棋盘上没有标记这件事是真的，记进路线图「后续候选」。
- **跟随系统外观**：值得做，但不属于对弈本身，记进「后续候选」。
- **原生菜单栏**：SDK 0.10.1 的自定义菜单仍会整条替换主菜单栏，丢掉编辑 / 显示 / 窗口，不做（同 v1.50 的结论）。
- **电脑的变化**：同样的着法连下三盘，入门 / 普通 / 困难的应手三盘都不同，不需要改。
- **棋盘木纹**：v2.1 已定不加。

## 这一版（v3.0）：一来一往

| 项 | 改什么 | 量什么 |
|---|---|---|
| 节奏 | 电脑最短 600ms；它的子落定约 250ms | 入门 / 普通回应 ≥ 600ms；预算与棋力闸门不动 |
| 落子 | 新子单独一层画，其余缓存；落子声换录音 | 动画期间不再整盘重画（重画次数 0）；点击的同步部分只做落子与画子 |
| 赢的那一刻 | 五子依次亮起，无红线红圈；停一拍再出卡片 | 连五到终局卡 ≥ 700ms；终局画面没有红线 |
| 再来一局 | 终局卡主按钮「再来一局」，一键开局 | 下完到下一盘 1 次点击；设置不变；「轮流」时换色 |
| 只有棋 | 下棋时收起计时器与时间线 | 下棋时顶栏没有计时器；时间线不占位，悬停 / 翻看 / 终局时出现 |
| 对手 | 极限用满时间；入门更常漏活三；四档整体下移一级（待定 5）；说明文字照实测改 | 每一档显著强于下一档（p < 0.05，发布时限）；新手对入门 ≥ 40%；每一档的说明逐句有实测 |
| 顺手修 | 坞边距、新局面板、输家座位 | 四种窗口下坞右边距 ≥ 20；面板不压卡片；对比度 ≥ 4.5 |

### 验收（闸门）

- 新闸门 `test-surface` S20，上表「量什么」每一条在 v2.1 上失败。
- 现有闸门照旧全部通过：棋力（等待加在算完之后，不进搜索时间）、对比度 AJ、布局、溢出。
- 时间线与计时器收起会动到几条旧闸门（T / W 顶栏、S17 时间线），照惯例逐条改写并在发布说明里列出。

### 工作量与风险

- **落子分层**（最大的一块）：`draw.js` 已有静态层缓存，只是动画期间绕过了它。改成「静态层不含新子 + 新子单画」，复盘、练习用的同一个画法不受影响。
- **节奏与「赢的那一刻」**：都是时序，加在落子和终局的流程里。测试里的电脑对局每手多几百毫秒，终局多不到 1 秒，闸门的超时要留够。
- **时间线收起**：时间线是翻看的入口，收起后要保证悬停、键盘、终局三条路都能把它叫出来，不然「翻看」会变成找不到的功能。
- **录音**：来源与授权是唯一的风险（见待定 3）。

### 需要你决定的

1. **版本号**：建议 **3.0.0**。对弈的节奏、终局、下一盘的路都变了。
2. **电脑最短落子时间**：建议 **600ms**；可选 400ms（更利落）/ 800ms（更从容）。
3. **落子声换录音**：建议**换**，这是手感里最直接的一项。要找能放心商用的录音（CC0），或者你自己录一段：黑白各落几子，手机录音就行，我来剪。找不到合适的，这一项单独顺延，不挡其余几项。
4. **计时器**：建议下棋时**不显示**，用时进终局卡。你如果喜欢看着时间下，就保留。
5. **四档下移一级**：建议**做**（见第七节）。只做修法 A（极限用满时间）也可以，那样入门与普通之间那道墙还在。
