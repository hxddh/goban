# v2.1 之后：v3.0 —— 棋盘自己讲

评估日期：2026-10-14。基准：main（v2.1.0）。要求：大版本，质变，提升品质。

## 方法

- 在 2 倍像素、近似苹方 / SF Pro 的字体下，把每个界面走了一遍：空盘、新局、对局中、电脑思考、终局、复盘、练习、⋯、设置、对局、快捷键。截图时模拟了 macOS 隐藏标题栏，和你装的 v2.1 看到的一样。
- 量了五样东西：
  - 电脑每一档的回应时间；
  - 启动时间；
  - 坞在四种窗口尺寸下离窗口边多远；
  - 新局弹层和初见卡片的重叠；
  - 终局时输家座位的对比度。
- 读了复盘、终局卡、练习里所有「讲道理」的文案，数了里面靠坐标说话的有几条。
- 查了 SDK 0.10.1：原生菜单、系统外观、窗口服务各能做什么。

## 结论先说

v2.0 让界面一眼看得懂，v2.1 让它看起来精致。剩下最大的差距不在界面上，在**这个应用最有价值的地方：它教你下棋的方式**。

复盘找出了你哪一手错、错在哪、该下哪里，这件事做得对，也有闸门证明。但它**用坐标讲**：

> 1. 当时白在 G9 下一手就能成五
> 2. 你落在了 D11
> 3. 对手于是在 G9 成五
> 4. 替代：挡在 G9（或抢先成五）

而棋盘默认**不显示坐标**（设置里「坐标」默认关）。用户要把「G9」在一块没有字母、没有数字的 15 × 15 网格上数出来，才知道说的是哪儿。复盘时棋盘上**一个标记都没有**，只有最后一手那个小点。

顶级的棋类应用不这么讲。它们让**棋盘自己讲**：
- 对手那条四连画一条线；
- 该下的地方放一个半透明的子；
- 你下错的那一手圈出来；
- 文字只剩一句，指着颜色说话。

一眼就懂，不用数格子。

这就是 v3.0 的质变：**从「读一段说明再去棋盘上找」，变成「看棋盘就懂」**。另外三件让它更像一个 mac 上的顶级应用：跟随系统外观、电脑落子有节奏、构图收好边。

## 一、复盘与终局卡：用坐标讲，而棋盘上什么都没有

实测（v2.1，复盘停在一手「可证明」的漏防上）：

| 项 | 现在 |
|---|---|
| 说明里出现的坐标 | 4 处（同一个点出现 3 次） |
| 棋盘上标出的点 | 0（只有最后一手的小圆点，那是本来就有的） |
| 棋盘上的坐标 | 默认关 |
| 说明的行数 | 4 行编号列表 + 一个「可证明」标签 |

按文案数：**复盘的 8 条说明靠 `{cell}` 坐标讲「哪里」**，终局卡的「替代：挡在 …」用的也是其中一条。练习早就不是这样了：答案点画在棋盘上，绿色带标号。复盘和终局卡是全应用里唯一还要你自己数格子的地方，偏偏它们是最有价值的地方。

### 这一版：棋盘自己讲

复盘停在一手失着上时，棋盘上画出：

| 标记 | 画法 | 什么时候有 |
|---|---|---|
| 你这一手 | 红圈 | 总有 |
| 对手的威胁 | 一条半透明红线，穿过对手那几颗连着的子 | 漏防、被反杀 |
| 该下的地方 | 你的颜色的半透明子 + 绿圈 | 总有（可证明的是成五点 / 挡点；引擎比较的是引擎首选） |
| 对手的惩罚 | 对手颜色的半透明子 | 与「该下的地方」不在同一点时才画 |

卡片上的四行编号说明收成**一句话，用颜色指着棋盘说**：

> 白在**红线**上已经四连，该挡在**绿点**；你下在了**红圈**。

- 坐标不丢：读屏仍念完整的坐标版；导出的 SGF 评注照旧带坐标；打开坐标显示时，句子末尾补上坐标。
- 「可证明」「引擎比较」「局势波动」这三个标签保留，但改成说人话的小字（「必错」「引擎认为」「局势下滑」），名字在 v3.0 里定稿时再对一遍。
- 终局卡「值得记住」那一行同样去掉坐标，只说「第 13 手漏防」；点「看复盘」就停在这一手，棋盘上已经画好了。
- 推演照旧：按下才在棋盘上摆出后续，标号的半透明子，和上面的标记不冲突（推演时上面的标记暂时收起）。

效果图（注入样式改的，只为看方向；图随评估一起发出，不进仓库）：之前是四行坐标；之后棋盘上一条红线、一个绿点、一个红圈，卡片一句话。

## 二、外观不跟系统走

- 应用不读系统的浅色 / 深色设置。新用户打开永远是「木」：深色界面。
- 在一台浅色模式的 Mac 上，整个系统是浅的，只有这个窗口是黑的。
- 「日」主题其实已经是一套像样的浅色界面（效果图里有），只是要用户自己去设置里找。

SDK 0.10.1 会发 `appearance_changed`，网页里 `prefers-color-scheme` 也跟系统同步，两条路都通。

### 这一版

- 主题多一个「**自动**」，作为新用户的默认：系统浅色用「日」，深色用「木」。系统一切换，窗口立刻跟着换，不用重开。
- 已经选过主题的老用户不动，仍是他选的那一套。
- 「夜」「本」两套照旧可选。

## 三、电脑落子没有节奏

实测从你落子到电脑那一子出现：

| 难度 | 回应时间（开局三手） |
|---|---|
| 入门 | 198–232ms |
| 普通 | 282–443ms |
| 困难 | 368–1074ms |

入门和普通几乎是**你手一抬，它的子就已经在了**。
- 下快棋的感觉是「对面没有人」，像在跟一个表格下棋。
- 落子的那 120ms 小动画和落子声，两颗子几乎叠在一起，听起来像一声。

顶级的对弈应用会给电脑一个**最短的「思考」时间**：不是让它变慢，而是让一来一往有节奏。

### 这一版

- 入门、普通：电脑落子**不早于你落子后 600ms**（这段时间座位里那三个点照常在动）。棋力不变，算法给的时间预算一毫秒不动，只是算完了等一等再落。
- 困难、极限：本来就超过这个时间，不变。
- 双人对局、练习、复盘：不涉及。

600ms 是建议值：大约是人看清一手棋、再落子的最短时间。

## 四、构图：卡片贴着窗口边，弹层压着卡片

**坞离窗口右边的距离，随窗口大小乱跳：**

| 窗口 | 坞右边距 | 棋盘左边距 |
|---|---|---|
| 1280 × 800（最常见） | **6px** | 286px |
| 1440 × 900 | 12px | 316px |
| 1024 × 700 | 56px | 56px |
| 1728 × 1080 | 66px | 370px |

最常见的两种尺寸，卡片几乎贴着窗口边，左边却空着近 300px。原因是坞的宽度按「棋盘右边剩多少就用多少」算，最少只留 `--stage-pad`（6px）。

**新局弹层与初见卡片叠在一起**：空盘时点「新局」，弹层（936–1236）盖在初见卡片（1018–1274）上，卡片右边那一截从弹层旁边露出来。

**终局时输家座位**：变淡后的「你」字对比度约 **3.2:1**，不到正文的 4.5:1。对比度闸门 AJ 没量到它，因为变淡是整颗座位一起降透明度。

### 这一版

- 坞离窗口边**至少 20px**，与棋盘之间仍是 24px。放不下时照 v1.75 的规则，棋盘与坞当成一组居中。
- 新局弹层打开时，初见卡片让开（收起，弹层关掉再回来）。
- 输家座位变淡改成换次要色，不再整颗降透明度。对比度 ≥ 4.5:1，仍然一眼看得出谁输。

## 五、看了、量了、这版不做的

- **原生菜单栏**：SDK 0.10.1 和 v1.50 查过的 0.8.1 一样，自定义菜单会**整条替换**主菜单栏（只留应用菜单），编辑 / 显示 / 窗口三个菜单一起没了。
  - SDK 有关窗口和最小化的服务，但没有切全屏的服务。自己做一套「显示 → 进入全屏」做不回来。
  - 只为把新局、悔棋放进菜单栏，就丢掉 ⌘M、⌃⌘F、窗口列表，不划算。v1.50 的结论不变。
- **棋盘木纹**：你在 v2.1 已经定了不加。
- **启动**：浏览器里首屏 52–60ms，页面就绪约 250ms。真机上的启动由 WKWebView 决定，网页这一侧没有可省的。

## 六、文档里过时的两条

`docs/ROADMAP.md` 的「明确不做」与「后续候选」里还写着：

- **禁手规则（Renju）**：「动 core + 双引擎，需先 spike」。禁手规则 v1.54 起就有，新局卡片里能选。
- **棋盘键盘可操作**：「明确不做」。v2.0 的快捷键说明里已有「方向键 + Enter 在棋盘上下棋」。

这一版一起改掉。

## 这一版（v3.0）：棋盘自己讲

| 项 | 改什么 | 量什么 |
|---|---|---|
| 复盘在棋盘上讲 | 你这一手红圈、对手威胁红线、该下的地方绿点、惩罚点；说明收成一句颜色话 | 复盘停在每一种失着上时，说明里提到的每个点都在棋盘上画出；看得见的说明里 0 个坐标（读屏与 SGF 照旧） |
| 终局卡 | 「值得记住」去掉坐标；看复盘停在这一手、标记已画好 | 同上 |
| 跟随系统外观 | 主题加「自动」，新用户默认；系统切换时实时跟随 | 模拟浅色 → 日、深色 → 木；切换后不用重开；老用户的选择不动 |
| 电脑落子节奏 | 入门、普通最短 600ms | 回应时间 ≥ 600ms；预算与棋力闸门不动 |
| 构图 | 坞离窗口边 ≥ 20px；新局弹层不压初见卡片；输家座位对比度 ≥ 4.5 | 四种窗口尺寸下量边距；弹层与卡片不相交；对比度 |
| 文档 | ROADMAP 两条过时条目 | — |

### 验收（闸门）

- 新闸门 `test-surface` S20，每一条在 v2.1 上失败：
  - 复盘时棋盘上的标记数等于说明里提到的点数；
  - 看得见的说明里没有坐标；
  - 「自动」主题跟随模拟的系统外观；
  - 入门 / 普通回应时间 ≥ 600ms；
  - 四种尺寸下坞右边距 ≥ 20；
  - 弹层与初见卡片不相交；
  - 输家座位对比度 ≥ 4.5。
- 现有闸门照旧全部通过：
  - 棋力闸门（强度测的是引擎，不受落子等待影响）；
  - 对比度 AJ（四套主题；「自动」只是在其中两套之间选）；
  - 布局闸门：终局 ↔ 复盘棋盘不动。

### 工作量与风险

- **复盘画标记**（主要工作量）：
  - 威胁线从局面里算。连着的同色子沿四个方向数，`core.js` 里已有 `collectLine`，不用引擎。
  - 标记画在 `draw.js` 的叠加层上，与提示、推演同一层，不重画棋盘。
  - 文案中英两套都要改。
  - 风险：引擎比较类的失着没有「威胁线」，只画红圈和绿点，说明要换一种句式。
- **系统外观**：只动主题的选择逻辑，四套主题本身不动。
- **落子节奏**：在电脑出手的地方加一个最短等待。测试里的电脑对局会变慢一点（每手多几百毫秒），闸门的超时要留够。
- **构图**：坞的宽度算法改一处，对 v1.75 的布局闸门要重新量一遍。

### 需要你决定的

1. **版本号**：叫 v3.0.0（复盘的讲法变了，是这个应用最核心的体验之一），还是 v2.2.0？我建议 **3.0.0**。
2. **电脑最短落子时间**：600ms 合适，还是更慢（800ms）/ 更快（400ms）？我建议 **600ms**。
3. **落子声要不要换成真实录音？** 现在的「哒」是用振荡器和噪声合成的，听得出是合成的。换成真实的蛤碁石落榧木盘的录音，手感会明显上一个台阶。但要找到能放心商用的录音（CC0 或自己录），这一版我还没找到可靠的来源。我建议**这一版不换**；你如果有录音或愿意录，给我就能换。
